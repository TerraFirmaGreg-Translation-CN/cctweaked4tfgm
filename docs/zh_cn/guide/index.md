# 指南

<VersionPill show-core />

群峦格雷现代版并没有 fork CC: Tweaked。它把上游 JAR 当作普通依赖引入，然后把周围的一切重写：配方、进度门槛、创造模式物品栏、任务章节、物品名覆盖。本指南把这两层分开，让你能分辨“这是 CC:T 本来的样子”和“这是群峦格雷改的”。

- [群峦格雷改了什么](/zh_cn/guide/differences) —— 逐项列出全部差异。
- [配方](/zh_cn/guide/recipes) —— 每个 CC:T 配方的格雷版。
- [海龟升级](/zh_cn/guide/turtle-upgrades) —— 73 个格雷工具升级。
- [进度](/zh_cn/guide/progression) —— 计算机什么时候可用，代价是什么。
- [语言与文本](/zh_cn/guide/language) —— UTF-8 支持与语言覆盖文件。
- [高级外设](/zh_cn/guide/advanced-peripherals) —— 群峦格雷保留的 CC 附属，以及被移除的部分。
- [上游与版本](/zh_cn/guide/upstream) —— CC:T 的发布节奏与群峦格雷的位置。
- [数据流水线](/zh_cn/guide/data-pipeline) —— 本站的数据怎么生成。

::: tip 从哪里开始
如果你从没用过 ComputerCraft，先读 CC:T 自己的[入门材料](https://tweaked.cc/mc-1.20.x/index.html)。本站记录的是**差异**，不是 Lua 语言本身。
:::
