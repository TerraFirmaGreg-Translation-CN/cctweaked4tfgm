CC: Tweaked 是 Minecraft 的一个模组，它为游戏添加了可编程计算机、海龟以及更多内容。作为深受喜爱的 ComputerCraft 的一个分支，它继承了其传统，并带来了改进的性能和稳定性，以及大量新功能。

CC: Tweaked 可以从 Modrinth 安装。它同时运行在 Minecraft Forge 和 Fabric 上。

功能

CC: Tweaked 的计算机使用 Lua 编程语言 进行控制，提供了开始编写代码和自动化你的 Minecraft 世界所需的所有工具。

尽管计算机非常强大，但它们无法移动，这使其受到相当大的限制。海龟 就是这里的解决方案。它们可以在世界中移动，放置和破坏方块，挥剑保护你免受僵尸伤害，或者做你编程让它们做的任何其他事情！

然而，并非所有问题都能用镐解决，因此 CC: Tweaked 还为你的计算机提供了一系列额外外设。你可以用扬声器演奏曲调，在显示器上显示文本或图像，用调制解调器将所有计算机连接在一起，以及更多。

计算机现在还可以与箱子等物品栏交互，让你能够构建复杂的物品栏和物品管理系统。
