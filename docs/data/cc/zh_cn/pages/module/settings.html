settings

读取和写入 CraftOS 及你的程序的配置选项。

当计算机启动时，它会从 /.settings 文件中读取 settings 的当前值。随后这些值可以被 读取或修改。

对某个设置项的任何修改，无论是通过加载文件（settings.load）还是直接设置它（settings.set、settings.unset），都会将 setting_changed 事件加入队列。程序可以监听该事件，以便在运行时重新加载 settings。

⚠ 警告

调用 settings.set 默认不会更新 settings 文件。你必须调用 settings.save 来持久化这些值。

用法

  • 定义一个基本设置项 123 并读取其值。

    settings.define("my.setting", {
    description = "An example setting",
    default = 123,
    type = "number",
})
print("my.setting = " .. settings.get("my.setting")) -- 123

    然后你可以使用 set 程序更改其值（例如 set my.setting 456），然后重新运行 example 程序以检查它是否已更改。

define(name [, options])Source

定义一个新的设置项，并可选指定关于它的各种属性。

虽然设置项不必在使用前添加，但这样做可以让你提供默认值和额外的元数据。

参数

  1. name string 此选项的名称
  2. options? { description? = string, default? = any, type? = string }

    此设置的选项。此表接受以下字段：

    • description：在运行 set 程序时可能会打印的描述。
    • default：默认值；如果该设置尚未更改，则由 settings.get 返回。
    • type：要求值必须为此类型。设置值为其他类型会出错。必须是以下之一："number"、"string"、"boolean" 或 "table"。

变更

  • 1.87.0 版本新增
undefine(name)Source

移除设置的 定义。

如果设置已被更改，这不会移除其值。请为此使用 settings.unset。

参数

  1. name string 此选项的名称

更改

  • 1.87.0 版本新增
set(name, value)Source

设置某设置的值。

⚠ 警告

调用 settings.set 默认不会更新 settings 文件。你必须调用 settings.save 来持久化这些值。

参数

  1. name string 要设置的设置名称
  2. value 该设置的值。此值不能为 nil，并且必须可被 textutils.serialize 序列化。

抛出

  • 如果此值无法被序列化

另见

  • settings.unset
get(name [, default])Source

获取某设置的值。

参数

  1. name string 要获取的设置名称。
  2. default? 如果此设置没有预先存在的值，则使用的值。如果未给出，则在该设置提供了默认值时使用其默认值，否则使用 nil。

返回

  1. 该设置的值；如果该设置尚未更改，则为默认值。

更改

  • 在版本 1.87.0 中更改： 现在如果预定义了默认值且 default 未设置，则会遵循默认值。
getDetails(name)Source

获取有关特定设置的详细信息。

参数

  1. name string 要获取的设置名称。

返回

  1. { description? = string, default? = any, type? = string, value? = any } 有关此设置的信息。这包括来自 settings.define 的所有信息，以及此设置的值。

更改

  • 1.87.0 版本新增
unset(name)Source

移除设置的值，将其设为默认值。

settings.get 将返回默认值，直到该设置的值被 设置，或计算机重新启动。

参数

  1. name string 要取消设置的设置名称。

另见

  • settings.set
  • settings.clear
clear()Source

重置所有设置的值。等同于对每个设置调用 settings.unset。

另见

  • settings.unset
getNames()Source

获取所有当前已定义设置的名称。

返回

  1. { string } 所有当前已定义设置的按字母顺序排序的列表。
load([path=".settings"])Source

从给定文件加载设置。

现有设置将与任何预先存在的设置合并。冲突的条目将被覆盖，但其他条目将被保留。

参数

  1. path? string = ".settings" 要从中加载的文件。

返回

  1. boolean 是否成功从此文件读取了设置。失败的原因可能包括文件不存在或已损坏。

另见

  • settings.save

更改

  • 在版本 1.87.0 中更改： path 现在为可选。
save([path=".settings"])Source

将设置保存到给定文件。

这将完全覆盖预先存在的文件。文件中定义但当前未加载的设置将被移除。

参数

  1. path? string = ".settings" 要保存设置到的路径。

返回

  1. boolean 设置是否成功保存。

另见

  • settings.load

更改

  • 在版本 1.87.0 中更改： path 现在为可选。
