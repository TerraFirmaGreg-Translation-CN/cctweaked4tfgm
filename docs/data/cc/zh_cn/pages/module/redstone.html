redstone

获取并设置与此计算机相邻的红石信号。

redstone 库提供了三种“类型”的红石控制：

  • 二进制输入/输出（setOutput/getInput）：这些仅检查红石线是否有任何输入或输出。信号强度 1 和 15 会被视为相同。
  • 模拟输入/输出（setAnalogOutput/getAnalogInput）：这些使用红石线的实际信号强度，范围为 0 到 15。
  • 捆绑线缆（setBundledOutput/getBundledInput）：这些会与“捆绑”线缆交互，例如 Project:Red 中的线缆。它们允许你发送 16 个独立的开/关信号。每个通道对应一种颜色，第一个为 colors.white，最后一个为 colors.black。

每当红石输入发生变化时，都会触发 redstone 事件。可用它来代替重复轮询。

此模块也可称为 rs。例如，可以调用 rs.getSides() 而不是 getSides。

用法

  • 每 0.5 秒切换计算机上方的红石信号。

    while true do
 redstone.setOutput("top", not redstone.getOutput("top"))
 sleep(0.5)
end

  • 以减法模式模拟红石比较器。

    while true do
 local rear = rs.getAnalogueInput("back")
 local sides = math.max(rs.getAnalogueInput("left"), rs.getAnalogueInput("right"))
 rs.setAnalogueOutput("front", math.max(rear - sides, 0))

 os.pullEvent("redstone") -- Wait for a change to inputs.
end

getSides()Source

返回一个包含计算机六个面的表。即 "top"、"bottom"、"left"、"right"、"front" 和 "back"。

返回

  1. { string... } 有效面的表。

变更

setOutput(side, on)Source

打开或关闭特定面的红石信号。

参数

  1. side string 要设置的面。
  2. on boolean 红石信号应开启还是关闭。开启时，会发出强度为 15 的信号。
getOutput(side)Source

获取指定面的当前红石输出。

参数

  1. side string 要获取的面。

返回值

  1. boolean 红石输出是开启还是关闭。

另见

  • setOutput
getInput(side)Source

获取指定面的当前红石输入。

参数

  1. side string 要获取的面。

返回值

  1. boolean 红石输入是开启还是关闭。
setAnalogOutput(side, value)Source

设置指定面的红石信号强度。

参数

  1. side string 要设置的面。
  2. value number 0 到 15 之间的信号强度。

抛出

  • 如果 value 不在 0 到 15 之间。

testBundledInput(side, mask)Source

判断给定面上一组特定颜色组合是否开启。

参数

  1. side string 要测试的面。
  2. mask number 要测试的掩码。

返回值

  1. boolean 这些颜色是否开启。

用法

  • 检查此方块上方的 colors.white 和 colors.black 是否开启。

    print(redstone.testBundledInput("top", colors.combine(colors.white, colors.black)))
