fs

与计算机的文件和文件系统交互，允许你操作文件、目录和路径。这包括：

  • 读取和写入文件： 调用 open 以获取文件“句柄”，可用于从文件读取或向文件写入。
  • 路径操作： combine、getName 和 getDir 允许你操作文件路径，将它们连接在一起或提取组成部分。
  • 查询路径： 例如，检查文件是否存在，或它是否为目录。参见 getSize、exists、isDir、isReadOnly 和 attributes。
  • 文件和目录操作： 例如，移动或复制文件。参见 makeDir、move、copy 和 delete。
🛈 注意

该 API 中的所有函数都基于绝对路径工作，并且不会考虑当前目录。你可以使用 shell.resolve 将相对路径转换为绝对路径。

挂载点

虽然一台计算机只能有一个硬盘和文件系统，但其他文件系统可以在其中被“挂载”。例如，磁盘驱动器外设会将其磁盘的内容挂载到 "disk/"、"disk1/" 等位置……

你可以使用 getDrive 函数查看某个路径属于哪个挂载点。对于计算机的主文件系统，它会返回 "hdd"（"/"）；对于 rom，它会返回 "rom"（"rom/"）。

大多数文件系统容量有限，任何会导致达到该容量的操作（例如写入一个极大的文件）都会失败。你可以使用 getCapacity 查看挂载点的容量，并使用 getFreeSpace 查看剩余空间。

complete(...)Source

为文件或目录名提供补全，适合与 _G.read 一起使用。

当某个目录是可能的补全候选时，会包含两个条目——一个带尾部斜杠（表示该目录内存在条目），另一个不带尾部斜杠（表示该条目是一个直接补全候选）。可将 include_dirs 设置为 false，以仅包含带尾部斜杠的条目。

参数

  1. path string 要补全的路径。
  2. location string 用于解析路径的位置。
  3. include_files? boolean = true 当 false 时，返回列表中将只包含目录。
  4. include_dirs? boolean = true 当 false 时，返回列表中将不会包含“raw”目录。

或

  1. path string 要补全的路径。
  2. location string 用于解析路径的位置。
  3. options { include_dirs? = boolean, include_files? = boolean, include_hidden? = boolean }

    此表形式是先前语法的扩展版本。上面的 include_files 和 include_dirs 参数会作为字段传入。

    此表还接受以下选项：

    • include_hidden：是否默认包含隐藏文件（以 . 开头的文件）。在输入 . 时它们仍会显示。

返回值

  1. { string... } 可能的补全候选列表。

用法

  • 补全根目录中的文件。

    read(nil, nil, function(str)
    return fs.complete(str, "", true, false)
end)

  • 补全根目录中的文件，默认隐藏隐藏文件。

    read(nil, nil, function(str)
    return fs.complete(str, "", {
        include_files = true,
        include_dirs = false,
        include_hidden = false,
    })
end)

find(path)Source

搜索与带通配符的字符串匹配的文件。

该字符串看起来像普通路径字符串，但可以包含通配符，从而匹配多个路径：

  • “?” 匹配文件名中的任意单个字符。
  • “*” 匹配任意数量的字符。

例如，rom/*/command* 将查找以 command 开头、位于 /rom 的任意子目录中的任何路径。

请注意，这些通配符只匹配路径的一个段。例如，rom/*.lua 会包含 rom/startup.lua，但 不会包含 rom/programs/list.lua。

参数

  1. path string 要搜索的带通配符限定的路径。

返回值

  1. { string... } 与搜索字符串匹配的路径列表。

抛出

  • 如果提供的路径无效。

用法

  • 列出帮助文件夹中的所有 Markdown 文件

    fs.find("rom/help/*.md")

变更

  • 1.6 版本新增
  • 1.106.0 版本更改： 添加了对 ? 通配符的支持。

open(path, mode)Source

打开位于某个路径的文件以进行读取或写入。

mode 字符串可以是以下任意一种：

  • "r"：读取模式。
  • "w"：写入模式。
  • "a"：追加模式。
  • "r+"：更新模式（允许读取和写入），所有数据都会保留。
  • "w+"：更新模式，所有数据都会被清除。

模式末尾也可以带有 "b"，这将以“二进制模式”打开文件。这会将 fs.ReadHandle.read 和 fs.WriteHandle.write 改为以数字而非字符串的形式读取/写入单个字节。此选项是为了向后兼容旧程序而存在，不建议在新代码中使用。

参数

  1. path string 要打开的文件路径。
  2. mode string 用于打开文件的模式。

返回

  1. table 该文件的文件句柄对象。

或

  1. nil 如果文件不存在或无法打开。
  2. string | nil 说明文件为何无法打开的消息。

抛出

  • 如果指定了无效模式。

用法

  • 读取文件内容。

    local file = fs.open("/rom/help/intro.txt", "r")
local contents = file.readAll()
file.close()

print(contents)

  • 打开文件并将所有行读入表中。io.lines 提供了完成此操作的另一种方法。

    local file = fs.open("/rom/motd.txt", "r")
local lines = {}
while true do
 local line = file.readLine()

 -- If line is nil then we've reached the end of the file and should stop
 if not line then break end

 lines[#lines + 1] = line
end

file.close()

print(lines[math.random(#lines)]) -- Pick a random line and print it.

  • 打开文件并向其中写入一些文本。你可以运行 edit out.txt 来查看写入的文本。

    local file = fs.open("out.txt", "w")
file.write("Just testing some code")
file.close() -- Remember to call close, otherwise changes may not be written!

变更

  • 在版本 1.109.0 中更改： 添加对更新模式（r+ 和 w+）的支持。
  • 在版本 1.109.0 中更改： 以非二进制模式打开文件现在使用文件的原始字节，而不是编码为 UTF-8。

attributes(path)Source

获取特定文件或文件夹的属性。

返回的属性表包含有关文件大小、是否为目录、创建时间和最后修改时间以及是否只读的信息。

创建和修改时间以自 UNIX 纪元以来的毫秒数给出。可以将其传给 os.date，以转换为更易用的形式。

参数

  1. path string 要获取属性的路径。

返回

  1. { size = number, isDir = boolean, isReadOnly = boolean, created = number, modified = number } 生成的属性。

抛出

  • 如果路径不存在。

另请参阅

  • getSize 如果你只关心文件的大小。
  • isDir 如果你只关心某路径是否为目录。

变更

  • 1.87.0 版本新增
  • 在版本 1.91.0 中更改： 将 modification 字段重命名为 modified。
  • 在版本 1.95.2 中更改： 向 attributes 添加了 isReadOnly。

ReadWriteHandle.seek([whence [, offset]])Source

在文件中定位到新位置，更改字节写入的位置。新位置是由 offset 给出的偏移量，相对于由 whence 确定的起始位置：

  • "set"：offset 相对于文件开头。
  • "cur"：相对于当前位置。这是默认值。
  • "end"：相对于文件末尾。

如果成功，seek 会返回从文件开头算起的新文件位置。

参数

  1. whence? string 偏移量相对于的位置。
  2. offset? number 要定位到的偏移量。

返回

  1. number 新位置。

或

  1. nil 如果定位失败。
  2. string 定位失败的原因。

抛出

  • 如果文件已关闭。

变更

  • 1.80pr1.9 版本新增
  • 在 1.109.0 版本中变更： 现在可用于所有文件句柄，而不仅仅是二进制模式句柄。

  1. whence? string 偏移量相对于的位置。
  2. offset? number 要定位到的偏移量。

返回

  1. number 新位置。

或

  1. nil 如果定位失败。
  2. string 定位失败的原因。

抛出

  • 如果文件已关闭。

变更

  • 1.80pr1.9 版本新增
  • 在 1.109.0 版本中变更： 现在可用于所有文件句柄，而不仅仅是二进制模式句柄。

抛出
