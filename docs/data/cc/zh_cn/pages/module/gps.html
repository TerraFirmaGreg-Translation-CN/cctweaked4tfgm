gps

使用 调制解调器 定位当前海龟或计算机的位置。

其工作原理是与其他已经知道自身位置的计算机（称为 GPS 主机）通信，使用 modem_message 找到到这些计算机的距离，并利用这些距离从它们的位置推导出自己的位置（这一过程称为 三边测量）。

locate([timeout=2 [, debug=false]])Source

尝试获取计算机或海龟自身的位置。

参数

  1. timeout? number = 2 确定自身位置所花费的最长时间（秒）。
  2. debug? boolean = false 打印调试消息

返回

  1. number 此计算机的 x 位置。
  2. number 此计算机的 y 位置。
  3. number 此计算机的 z 位置。

或

  1. nil 如果无法确定位置。
