multishell

Multishell 允许同时运行多个程序。

当多个程序正在运行时，它会在屏幕顶部显示一个标签栏，允许你在程序之间切换。可以使用 fg 或 bg 程序启动新程序，或使用 shell.openTab 和 multishell.launch 函数。

每个进程由其 ID 标识，该 ID 对应于其在标签列表中的位置。由于标签可能被打开和关闭，这个 ID 在程序运行期间不是恒定的。因此，请注意不要使用过期的 ID。

与 shell 一样，multishell 并不是一个“真正”的 API。相反，它是一个标准程序，会启动一个命令行并将其 API 注入到命令行的环境中。此 API 在全局环境中不可用，因此对 API 也不可用。

getFocus()Source

获取当前可见的进程。这将是标签栏上选中的那个进程。

注意，这与 getCurrent 不同，后者返回当前正在执行的进程。

返回值

  1. number 当前可见进程的索引。

另请参见

  • setFocus
setFocus(n)Source

更改当前可见的进程。

参数

  1. n number 要切换到的进程索引。

返回值

  1. boolean 如果进程已成功更改。如果没有具有此 ID 的进程，这将返回 false。

另请参见

  • getFocus
getTitle(n)Source

获取给定标签的标题。

这最初是程序的名称，但可以使用 multishell.setTitle 更改。

参数

  1. n number 进程索引。

返回值

  1. string | nil 当前进程标题，如果进程不存在则为 nil。
setTitle(n, title)Source

设置给定进程的标题。

参数

  1. n number 进程索引。
  2. title string 新的进程标题。

用法

  • 更改当前进程的标题

    multishell.setTitle(multishell.getCurrent(), "Hello")

  • getTitle
getCurrent()Source

获取当前正在运行的进程的索引。

返回值

  1. number 当前正在运行的进程。
launch(tProgramEnv, sProgramPath, ...)Source

使用给定的环境、程序和参数启动一个新进程。

返回的进程索引在程序运行期间不是恒定的。它可以在启动后立即安全使用（例如，用于更新标题或切换到该标签）。但是，在你的程序让出执行权后，它可能不再正确。

参数

  1. tProgramEnv table 用于加载该路径的环境。
  2. sProgramPath string 要运行的程序路径。
  3. ... 要传递给程序的额外参数。

返回值

  1. number 已创建进程的索引。

用法

  • 运行“hello”程序，并将其标题设置为“Hello!”

    local id = multishell.launch({}, "/rom/programs/fun/hello.lua")
multishell.setTitle(id, "Hello!")
