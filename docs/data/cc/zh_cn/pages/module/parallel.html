parallel

一种同时运行多个函数的简单方法。

函数实际上不会同时执行，而是此 API 会在它们让出控制权时自动在它们之间切换（例如，当它们调用 coroutine.yield 时，或调用该函数的函数——例如 os.pullEvent——或调用该函数的函数，等等——基本上，任何导致函数“暂停”的操作）。

每个以“并行”方式执行的函数都会获得自己的事件队列副本，因此“消费事件”的函数（同样，大多是指任何导致脚本暂停的操作——例如 os.sleep、rednet.receive、turtle API 的大部分内容等）可以安全地在其中一个函数中使用，而不会影响另一个函数所访问的事件队列。

⚠ 警告

使用此 API 时，请注意传入你希望并行运行的函数，而 不是 调用这些函数的结果。

例如，下面是正确的：

local function do_sleep() sleep(1) end
parallel.waitForAny(do_sleep, rednet.receive)

但下面 不是：

local function do_sleep() sleep(1) end
parallel.waitForAny(do_sleep(), rednet.receive)

waitForAny(...)Source

在这些函数的执行之间切换，直到其中任意一个完成。如果任一函数出错，错误消息会从 parallel.waitForAny 调用向上传播。

参数

  1. ... function 要并行运行的函数。

用法

  • 每秒打印一条消息，直到按下 q 键。

    local function tick()
    while true do
        os.sleep(1)
        print("Tick")
    end
end
local function wait_for_q()
    repeat
        local _, key = os.pullEvent("key")
    until key == keys.q
    print("Q was pressed!")
end

parallel.waitForAny(tick, wait_for_q)
print("Everything done!")
waitForAll(...)Source

并行运行多个函数，直到它们全部完成。

如果任一函数出错，其他函数不会恢复执行，并且错误会向上传播。

⚠ 警告

虽然可以并行运行任意数量的函数，但并行运行过多内容有时会导致问题：

  • 计算机一次只缓冲 256 个事件。尝试并行运行数百个函数（尤其是在调用外设方法时）可能导致事件队列被填满，从而导致事件被丢弃，程序卡住。
  • 计算机一次只运行 16 个 HTTP 请求。尝试并行运行超过此数量的请求将没有效果。

生成新的并行函数

在某些情况下，你可能希望从现有的 parallel.waitForAll 调用开始并行运行额外函数。传递给 waitForAll 的每个函数都可以接受一个 spawn 参数，可以调用它来生成新的并行函数。

parallel.waitForAll(function(spawn)
    spawn(function() sleep(1); print("Finished 1") end)
    spawn(function() sleep(2); print("Finished 2") end)
end)

参数

  1. ... function(spawn: function(fn: function, ...: any)) 要并行运行的函数。

用法

  • 启动两个计时器并等待它们都运行。

    local function a()
    os.sleep(1)
    print("A is done")
end
local function b()
    os.sleep(3)
    print("B is done")
end

parallel.waitForAll(a, b)
print("Everything done!")

  • 生成要并行运行的函数列表。

    local funcs = {}
for i = 1, 5 do
    table.insert(funcs, function()
        sleep(math.random())
        print("Finished " .. i)
    end)
end

parallel.waitForAll(table.unpack(funcs))
print("Everything done!")

  • 从 waitForAll 内部并行运行新函数。

    parallel.waitForAll(function(spawn)
    for i = 1, 5 do
        spawn(function()
            sleep(math.random())
            print("Finished " .. i)
        end)
    end
end)
print("Everything done!")
