pocket

控制当前口袋计算机，添加或移除升级。

此 API 仅在便携式计算机上可用。因此，你可以利用它是否存在来判断自己正在使用哪种计算机：

if pocket then
 print("On a pocket computer")
else
 print("On something else")
end

equipBack()Source

在玩家的物品栏中搜索另一个升级，如果找到，则用该物品替换现有的升级。

此物品栏搜索从玩家当前选中的槽位开始，允许你对升级进行优先级排序。

返回值

  1. boolean 物品是否已装备。
  2. string | nil 物品未被装备的原因。
unequipBack()Source

移除便携式计算机当前的升级。

返回值

  1. boolean 升级是否已卸下。
  2. string | nil 升级未被卸下的原因。
