sleep([time=0])Source

将执行暂停指定的秒数。

由于它会等待固定数量的世界刻，time 会自动向上舍入到最接近的 0.05 秒的倍数。如果你使用协程或 parallel API，它只会暂停当前线程的执行，而不是整个程序。

提示

因为 sleep 内部使用计时器，所以它是一个会让出的函数。这意味着你可以用它来防止“Too long without yielding”错误。然而，由于最短休眠时间为 0.05 秒，它会使你的程序变慢。

⚠ 警告

在内部，此函数会排队并等待一个计时器事件（使用 os.startTimer），但它不会监听任何其他事件。这意味着休眠期间发生的任何事件都会被完全丢弃。如果你需要在休眠时接收事件，请考虑使用 timers，或 parallel API。

参数

  1. time? number = 0 休眠的秒数，向上舍入到最接近的 0.05 的倍数。

用法

  • 休眠三秒。

    print("Sleeping for three seconds")
sleep(3)
print("Done!")

参见

  • os.startTimer

变更

  • 在 1.63 版本中更改： time 参数现在是可选的。

read([replaceChar [, history [, completeFn [, default]]]])Source

从终端读取用户输入。它会自动处理方向键、粘贴、字符替换、历史记录回滚、自动补全和默认值。

参数

  1. replaceChar? string 用于替换每个输入字符的字符。例如，这可用于隐藏密码。
  2. history? table 一个保存历史记录项的表，可使用上/下方向键回滚到这些项。最旧的项位于索引 1，而最新的项位于最高索引。
  3. completeFn? function(partial: string):{ string... } | nil 用于补全的函数。此函数应接收到目前为止输入的部分文本，并返回可能的补全选项列表。
  4. default? string 应已输入到提示符中的默认文本。

返回

  1. string 输入的文本。

用法

  • 读取一个字符串并将其回显给用户

    write("> ")
local msg = read()
print(msg)

  • 提示用户输入密码。

    while true do
  write("Password> ")
  local pwd = read("*")
  if pwd == "let me in" then break end
  print("Incorrect password, try again.")
end
print("Logged in!")

  • 一个包含补全、历史记录和默认值的完整示例。

    local completion = require "cc.completion"
local history = { "potato", "orange", "apple" }
local choices = { "apple", "orange", "banana", "strawberry" }
write("> ")
local msg = read(nil, history, function(text) return completion.choice(text, choices) end, "app")
print(msg)

参见

  • cc.completion 用于帮助补全的函数。

更改

  • 在 1.74 版本中更改： 添加了 completeFn 参数。
  • 在 1.80pr1 版本中更改： 添加了 default 参数。
_HOSTSource

存储当前的 ComputerCraft 和 Minecraft 版本。

在 Minecraft 之外（例如在模拟器中），_HOST 将改为包含模拟器的版本。

如果你需要检查某个功能是否存在，通常最好依赖功能检测，而不是比较模组或 Minecraft 版本。

例如，ComputerCraft 1.93.0 (Minecraft 1.15.2)。

用法

  • 打印当前计算机的环境。

    print(_HOST)

参见

  • os.version

更改

  • 1.76 版本新增
_CC_DEFAULT_SETTINGSSource

ComputerCraft 配置中定义的默认计算机设置。

这是由模组配置或服务器所有者定义的、以逗号分隔的设置对列表。默认情况下，它为空。

用于禁用自动补全的示例值：

shell.autocomplete=false,lua.autocomplete=false,edit.autocomplete=false

用法

  • _CC_DEFAULT_SETTINGS

更改

  • 1.77 版本新增
