stdinSource

表示“标准输入”的文件句柄。从此文件读取会提示用户输入。

stdoutSource

表示“标准输出”的文件句柄。写入此文件会将写入的文本显示在屏幕上。

stderrSource

表示“标准错误”流的文件句柄。

可以使用它来显示错误信息，写入其中的内容会显示在终端上。

lines([filename, ...])Source

以读取模式打开给定的文件名，并返回一个迭代器；每次调用它时，都会从文件中返回一个新行。

这可以在 for 循环中用于遍历文件的所有行

一旦到达文件末尾，将返回 nil。文件会自动关闭。

如果未提供文件名，则会使用当前输入。在这种情况下，不会使用该句柄。

参数

  1. filename? string 要从中提取行的文件名
  2. ... 要针对每一行传递给 Handle:read 的参数。

返回

  1. function():string | nil The line iterator.

抛出

  • 如果文件无法以读取方式打开

用法

  • 遍历文件中的每一行并将其打印出来。

    for line in io.lines("/rom/help/intro.txt") do
  print(line)
end

参见

  • Handle:lines
  • io.input

变更

  • 1.55 版本新增
open(filename [, mode])Source

使用给定模式打开文件，要么返回新的文件句柄，要么返回 nil，并附带一条错误信息。

mode 字符串可以是以下任意一项：

  • "r"：读取模式。
  • "w"：写入模式。
  • "a"：追加模式。
  • "r+"：更新模式（允许读取和写入），所有数据都会保留。
  • "w+"：更新模式，所有数据都会被清除。

模式还可以在末尾带有一个 b，这将以“二进制模式”打开文件。这对功能没有影响。

参数

  1. filename string 要打开的文件名。
  2. mode? string 打开文件时使用的模式。默认为 r。

返回

  1. Handle 已打开的文件。

或者

  1. nil 发生错误时。
  2. string 文件无法打开的原因。

变更

  • 1.111.0 版本中的变更： 添加对 r+ 和 w+ 的支持。

Handle.lines(...)Source

返回一个迭代器，每次调用时都会从文件中返回新的一行。

这可用于 for 循环中以遍历文件的所有行

一旦到达文件末尾，将返回 nil。文件不会自动关闭。

参数

  1. ... 要针对每一行传递给 Handle:read 的参数。

返回

  1. function():string | nil The line iterator.

抛出

  • 如果文件无法以读取方式打开

用法

  • 遍历文件中的每一行并将其打印出来。

for line in file:lines() do
  print(line)

Handle.read(...)Source

使用指定格式从文件中读取数据。对于提供的每种格式，函数会返回读取到的数据，或在无法读取数据时返回 nil。

可用格式如下：

  • l：返回下一行（末尾不带换行符）。
  • L：返回下一行（末尾带换行符）。
  • a：返回文件剩余的全部内容。
  • n：返回一个数字（在 CC 中未实现）。

这些格式前可以加上 * 以兼容 Lua 5.1。

如果未提供格式，则假定为 l。

参数

  1. ... 要使用的格式。

返回

  1. string | nil... 从文件中读取的数据。
Handle.seek([whence [, offset]])Source

将文件光标移动到指定位置，并返回新位置。

whence 控制定位操作的起始位置，是一个可为以下三个值之一的字符串：

  • set：基准位置为 0（文件开头）
  • cur：基准为当前位置
  • end：基准为文件末尾

whence 的默认值为 cur，offset 的默认值为 0。这意味着不带参数的 file:seek() 会返回当前位置而不移动。

参数

  1. whence? string 设置光标时的起始位置。
  2. offset? number 要移动到的偏移量（相对于起点）。

返回

  1. number 文件光标的新位置。
