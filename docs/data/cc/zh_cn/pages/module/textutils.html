slowWrite(text [, rate])Source

在当前光标位置逐字符缓慢写入字符串 text。

与 _G.write 类似，这不会在末尾插入换行符。

参数

  1. text string 要写入屏幕的文本
  2. rate? number 每秒写入的字符数，默认为 20。

用法

  • textutils.slowWrite("Hello, world!")
  • textutils.slowWrite("Hello, world!", 5)

变更

  • 1.3 版本新增
slowPrint(sText [, nRate])Source

在当前光标位置逐字符缓慢打印字符串 text。

与 print 类似，这会在打印后插入一个换行符。

参数

  1. sText string 要写入屏幕的文本
  2. nRate? number 每秒写入的字符数，默认为 20。

用法

  • textutils.slowPrint("Hello, world!")
  • textutils.slowPrint("Hello, world!", 5)
formatTime(nTime [, bTwentyFourHour])Source

接收输入时间并将其格式化为更易读的形式，例如 6:30 PM。

参数

  1. nTime number 要格式化的时间，由 os.time 提供。
  2. bTwentyFourHour? boolean 是否将其格式化为 24 小时制（18:30）而不是 12 小时制（6:30 AM）

返回值

  1. string 格式化后的时间

用法

  • 以 12 小时制打印当前游戏内时间。

    textutils.formatTime(os.time())

  • 以 24 小时制打印本地时间。

    textutils.formatTime(os.time("local"), true)
pagedPrint(text [, free_lines])Source

将给定字符串打印到屏幕。

如果无需滚动即可完成该操作，其行为与 print 大致相同；否则，它会在屏幕底部弹出“按任意键继续”提示。每次按键都会使其向下滚动，并在再次提示前（如有需要）再多写入一行。

参数

  1. text string 要打印到屏幕的文本。
  2. free_lines? number 在首次提示出现前自动滚动的行数（意味着将打印 free_lines + 1 行）。可将其设置为光标的 y 坐标 - 2，以始终尝试填满屏幕。默认为 0，表示在提示前只显示一行。

返回值

  1. number 已打印的行数。

用法

  • 生成若干行文本并打印，在到达终端底部时分页。

    local lines = {}
for i = 1, 30 do lines[i] = ("This is line #%d"):format(i) end
local message = table.concat(lines, "\n")

local width, height = term.getCursorPos()
textutils.pagedPrint(message, height - 2)
tabulate(...)Source

以结构化形式打印表格。

它接受多个参数，可以是表或数字。遇到表时，该表将被视为一行表格，每列宽度会自动调整。

遇到数字时，它会将后续行的文本颜色设置为该数字。

参数

  1. ... { string... } | number 要显示的行和文本颜色。

用法

  • textutils.tabulate(
  colors.orange, { "1", "2", "3" },
  colors.lightBlue, { "A", "B", "C" }
)

变更

  • 1.3 版本新增
pagedTabulate(...)Source

以结构化形式打印表格；如果结果无法在终端中完整显示，则暂停并提示输入。

其功能与 textutils.tabulate 完全相同，但如果整个输出无法在屏幕中完整显示，则会提示用户输入。

参数

  1. ... { string... } | number 要显示的行和文本颜色。

用法

  • 生成一个长表格，对其进行制表并打印到屏幕。

    local rows = {}
for i = 1, 30 do rows[i] = {("Row #%d"):format(i), math.random(1, 400)} end

textutils.pagedTabulate(colors.orange, {"Column", "Value"}, colors.lightBlue, table.unpack(rows))

另见

  • textutils.tabulate
  • textutils.pagedPrint

serialize(t, opts)Source

将 Lua 对象转换为文本表示，适合保存到文件或进行美化打印。

参数

  1. t 要序列化的对象
  2. opts { compact? = boolean, allow_repetitions? = boolean }

    序列化选项。

    • compact：不要在各项之间输出缩进和其他空白。
    • allow_repetitions：放宽对递归表的检查，允许它们多次出现（只要表不出现在自身内部）。

返回值

  1. string 序列化后的表示

抛出

  • 如果对象包含无法序列化的值。这包括函数以及多次出现的表。

用法

  • 序列化一个基本表。

    textutils.serialise({ 1, 2, 3, a = 1, ["another key"] = { true } })

  • 演示一些其他选项

    local tbl = { 1, 2, 3 }
print(textutils.serialise({ tbl, tbl }, { allow_repetitions = true }))

print(textutils.serialise(tbl, { compact = true }))

参见

  • cc.pretty.pretty_print 显示表的另一种方式，通常更适合美化打印。

变更

  • 1.3 版本新增
  • 在版本 1.97.0 中变更： 添加了 opts 参数。

serializeJSON(...)Source

返回给定数据的 JSON 表示。

这主要用于与 commands API 中的各种函数交互，不过也可用于发起 http 请求。

Lua 的数据模型与 Javascript/JSON 有较大不同。因此，一些 Lua 值无法干净地序列化为 JSON。

  • Lua 表可以包含任意键值对，但 JSON 只接受数组和对象（对象要求字符串键）。序列化表时，如果它只有数字键，则会被视为数组。否则，表将使用字符串键序列化为对象。非字符串键（例如数字或表）将被丢弃。

    这样做的结果是，空表始终会被序列化为对象，而不是数组。可以使用 textutils.empty_json_array 来表示空数组。

  • Lua 字符串是原始字节序列，并且没有特定编码。然而，JSON 字符串必须是有效的 Unicode。默认情况下，字符串中的非 ASCII 字符会被序列化为其 Unicode 码位（例如，"\xfe" 会被转换为 "\u00fe"）。可以设置 unicode_strings 选项，将所有输入字符串视为 UTF-8。

  • Lua 不区分缺失的键（JS 中的 undefined）和显式设置为 null 的键。因此，{ x = nil } 会被序列化为 {}。可以使用 textutils.json_null 来获得显式的 null 值（{ x = textutils.json_null } 会序列化为 {"x": null}）。

参数

  1. t 要序列化的值。与 textutils.serialise 一样，这不应包含递归表或函数。
  2. options? { nbt_style? = boolean, unicode_strings? = boolean, allow_repetitions? = boolean }

    序列化选项。

    • nbt_style：是否生成 NBT 风格的 JSON（键不带引号）而不是标准 JSON。
    • unicode_strings：是否将字符串视为包含 UTF-8 字符，而不是使用默认的 8 位字符集。
    • allow_repetitions：放宽对递归表的检查，允许它们多次出现（只要表不出现在自身内部）。

或

  1. t 要序列化的值。与 textutils.serialise 一样，这不应包含递归表或函数。
  2. bNBTStyle boolean 是否生成 NBT 风格的 JSON（键不带引号）而不是标准 JSON。

返回值

  1. string 输入的 JSON 表示。

抛出

  • 如果对象包含无法序列化的值。这包括函数以及多次出现的表。

用法

  • 序列化一个简单对象

    textutils.serialiseJSON({ values = { 1, "2", true } })

  • 将对象序列化为 NBT 风格字符串

    textutils.serialiseJSON({ values = { 1, "2", true } }, { nbt_style = true })

参见

  • textutils.json_null 用于序列化 JSON null 值。
  • textutils.empty_json_array 用于序列化 JSON 空数组。

变更

  • 新增于版本 1.7
  • 在版本 1.106.0 中变更： 添加了 options 重载和 unicode_strings 选项。
  • 在版本 1.109.0 中变更： 添加了 allow_repetitions 选项。

unserializeJSON(s [, options])Source

将序列化的 JSON 字符串转换回重新组装的 Lua 对象。

这可以与 textutils.serializeJSON 一起使用，也可在命令方块或 Web API 通信时使用。

如果遇到 null 值，它会被转换为 nil。它可以转换为 textutils.json_null，只需使用 parse_null 选项。

如果遇到空数组，它会被转换为 textutils.empty_json_array。可以通过 parse_empty_array 选项将其转换为新的空表。

参数

  1. s string 要反序列化的序列化字符串。
  2. options? { nbt_style? = boolean, parse_null? = boolean, parse_empty_array? = boolean }

    控制此 JSON 对象解析方式的选项。

    • nbt_style：当为 true 时，将接受字符串化 NBT字符串，正如许多命令所生成的那样。

      与 JSON 不同，SNBT 字符串的格式会在 Minecraft 版本之间发生变化。此函数应解析命令返回的所有 SNBT 字符串，但可能不会接受所有有效的 SNBT 字符串。例如，目前不支持 bool 和 uuid 函数。

    • parse_null：当为 true 时，null 将被解析为 json_null，而不是 nil。

    • parse_empty_array：当为 false 时，空数组将被解析为一个新表。默认情况下（或当此值为 true 时），它们会被解析为 empty_json_array。

返回值

  1. 反序列化后的对象

或

  1. nil 如果对象无法反序列化。
  2. string 描述 JSON 字符串为何无效的消息。

用法

  • 反序列化一个基本 JSON 对象

    textutils.unserialiseJSON('{"name": "Steve", "age": null}')

  • 反序列化一个基本 JSON 对象，并将 null 值返回为 json_null。

    textutils.unserialiseJSON('{"name": "Steve", "age": null}', { parse_null = true })

参见

  • textutils.json_null 用于序列化 JSON null 值。
  • textutils.empty_json_array 用于序列化 JSON 空数组。

变更

  • 1.87.0 版本新增
  • 在版本 1.100.6 中更改： 添加了 parse_empty_array 选项

complete(sSearchText [, tSearchTable])Source

为不完整的 Lua 表达式提供可能的补全列表。

如果补全的元素是表，则建议项后会追加 .。类似地，函数后会追加 (。

参数

  1. sSearchText string 要补全的部分表达式，例如变量名或表索引。
  2. tSearchTable? table 要在其中查找变量的表，默认为全局环境（_G）。该函数还会通过 __index 元表字段搜索“父”环境。

返回值

  1. { string... } （可能为空的）补全列表。

用法

  • textutils.complete( "pa", _ENV )

另请参阅

  • shell.setCompletionFunction
  • _G.read

更改

  • 新增于版本 1.74
