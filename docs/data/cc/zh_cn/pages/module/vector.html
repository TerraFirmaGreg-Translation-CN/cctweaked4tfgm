向量

基本的 3D 矢量类型和一些常见的矢量运算。当使用 Minecraft 世界中的坐标（例如来自 gps API 的坐标）时，这可能很有用。

关于向量的介绍可以在维基百科上找到。

更改

  • 1.31 版本新增

new(x, y, z)Source

使用给定坐标构造一个新的Vector。

参数

  1. x number 矢量的 X 坐标或方向。
  2. y number 矢量的 Y 坐标或方向。
  3. z number 向量的 Z 坐标或方向。

返回

  1. Vector 构造的向量。

类型

向量

3 维向量，具有 x、y 和 z 值。

这适用于表示位置向量和方向向量。

Vector:add(o)Source

将两个向量相加。

参数

  1. o Vector 要相加的第二个向量。

返回

  1. Vector 结果向量

用法

  • v1:add(v2)
  • v1 + v2
Vector:sub(o)Source

用一个向量减去另一个向量。

参数

  1. o Vector 要减去的向量。

返回

  1. Vector 结果向量

用法

  • v1:sub(v2)
  • v1 - v2
Vector:mul(factor)Source

将向量乘以标量值。

参数

  1. factor number 要相乘的标量值。

返回

  1. Vector 值为 (x * m, y * m, z * m) 的向量。

用法

  • vector.new(1, 2, 3):mul(3)
  • vector.new(1, 2, 3) * 3
Vector:div(factor)Source

将向量除以标量值。

参数

  1. factor number 要除以的标量值。

返回

  1. Vector 值为 (x / m, y / m, z / m) 的向量。

用法

  • vector.new(1, 2, 3):div(3)
  • vector.new(1, 2, 3) / 3
Vector:unm()Source

对向量取反

返回

  1. Vector 负向量。

用法

  • -vector.new(1, 2, 3)
Vector:dot(o)Source

计算两个向量的点积

参数

  1. o Vector 要计算点积的第二个向量。

返回

  1. number self 和 o 的点积。

用法

  • v1:dot(v2)
Vector:cross(o)Source

计算两个向量的叉积

参数

  1. o Vector 要计算叉积的第二个向量。

返回

  1. Vector self 和 o 的叉积。

用法

  • v1:cross(v2)
Vector:length()Source

获取该向量的长度（也称为幅度）。

返回

  1. number 该向量的长度。
Vector:normalize()Source

将此向量除以它的长度，产生相同的方向，但长度为 1。

返回

  1. Vector 归一化向量

用法

  • v:normalize()
Vector:round([tolerance])Source

构造一个向量，每个维度四舍五入到最接近的值。

参数

  1. tolerance? number 我们应该舍入的容差，默认为 1。例如，容差 0.5 将舍入到最接近的 0.5。

返回

  1. Vector 舍入向量。
Vector:tostring()Source

将此向量转换为字符串，以便于打印。

返回

  1. string 此向量的字符串表示形式。

用法

  • v:tostring()
  • tostring(v)
Vector:equals(other)Source

检查两个向量之间是否相等。

参数

  1. other Vector 要比较的第二个向量。

返回

  1. boolean 向量是否相等。
