peripheral

查找并控制连接到此计算机的外设。

外设是可以由计算机控制的方块（或海龟和口袋计算机升级）。例如，speaker 外设允许计算机播放音乐，monitor 外设允许你在世界中显示文本。

引用外设

计算机可以与相邻的外设交互。每个外设都会根据其所处方向获得一个名称。例如，计算机下方的磁盘驱动器在你的 Lua 代码中会被称为 "bottom"，左侧的则称为 "left"，所有 6 个方向依此类推（"bottom"、"top"、"left"、"right"、"front"、"back"）。

你可以使用 peripherals 程序或 peripheral.getNames 函数列出所有外设的名称。

也可以使用 有线调制解调器 来使用距离计算机较远的外设。将一个调制解调器放在计算机旁边（你可能需要潜行并右键单击），将网络电缆连接到外设，然后再将另一个调制解调器放在该方块旁边。然后你可以右键单击调制解调器来使用（或 attach）该外设。这会将外设名称打印到聊天栏，之后就可以像方向名称一样使用它来访问该外设。你可以单击消息将名称复制到剪贴板。

使用外设

一旦获得外设的名称，就可以使用 peripheral.call 函数调用其上的函数。该函数接收外设的名称、要调用的函数名称，然后是其参数。

🛈 信息

外设 API 的某些部分将外设函数称为 方法（例如 peripheral.getMethods 函数）。别担心，它们是一回事！

假设我们的计算机上方有一个显示器（因此方向是“top”），并且想 向它写入一些文本。我们会这样写：

peripheral.call("top", "write", "This is displayed on a monitor!")

一旦开始进行几次外设调用，这可能会变得非常重复，因此我们可以 wrap 一个外设。这会构建一个包含该外设所有函数的表，因此你可以像使用 API 或模块一样使用它。

例如，我们可以将上面的示例写成如下形式：

local my_monitor = peripheral.wrap("top")
my_monitor.write("This is displayed on a monitor!")

查找外设

有时在编写程序时，你并不关心外设叫什么名字，你只需要知道它存在。例如，如果你正在编写一个音乐播放器，你只需要一个扬声器——它在计算机上方还是下方并不重要。

幸运的是，有一种快速的方法可以做到这一点：peripheral.find。它接受一个外设类型，并返回所有属于该类型的已连接外设。

那么什么是外设类型呢？它是一个字符串，描述外设是什么，以及因此有哪些函数可用。例如，扬声器就称为 "speaker"，显示器称为 "monitor"。有些外设可能有多个类型——Minecraft 箱子既是 "minecraft:chest" 也是 "inventory"。

你可以使用 peripheral.getType 获取一个外设的所有类型，并使用 peripheral.hasType 检查一个外设是否为特定类型。

回到我们最初的示例，让我们使用 peripheral.find 来查找一个已连接的扬声器：

local speaker = peripheral.find("speaker")
speaker.playNote("harp")

另请参阅

  • peripheral 每当连接新外设时触发此事件。
  • peripheral_detach 每当外设断开连接时触发此事件。

getNames()Source

提供所有可用外设的列表。

如果设备直接位于系统旁边，则其名称将列为其所连接的侧面。如果设备通过有线调制解调器连接，则将根据其在有线网络上的名称进行报告。

返回值

  1. { string... } 所有已连接外设的名称列表。

更改

  • 1.51 版本新增
isPresent(name)Source

判断是否存在具有给定名称的外设。

参数

  1. name string 要检查的侧面或网络名称。

返回值

  1. boolean 是否存在具有给定名称的外设。

用法

  • peripheral.isPresent("top")
  • peripheral.isPresent("monitor_0")
getType(peripheral)Source

获取具名或已包装外设的类型。

参数

  1. peripheral string | table 要查找的外设名称，或一个已包装的外设实例。

返回值

  1. string... 外设的类型，如果外设不存在则为 nil。

用法

  • 获取此计算机上方外设的类型。

    peripheral.getType("top")

更改

  • 在版本 1.88.0 中更改： 接受已包装的外设作为参数。
  • 在版本 1.99 中更改： 现在返回多个类型。
hasType(peripheral, peripheral_type)Source

检查外设是否为特定类型。

参数

  1. peripheral string | table 外设的名称或已包装的外设实例。
  2. peripheral_type string 要检查的类型。

返回值

  1. boolean | nil 如果外设具有特定类型，或在外设不存在时为 nil。

更改

call(name, method, ...)Source

在具有给定名称的外设上调用方法。

参数

  1. name string 要在其上调用方法的外设名称。
  2. method string 方法的名称
  3. ... 要传递给方法的额外参数

返回值

  1. 外设方法的返回值。

用法

  • 打开此计算机顶部的调制解调器。

    peripheral.call("top", "open", 1)
wrap(name)Source

获取一个包含外设上所有可用函数的表。之后可以调用这些函数，而不必每次都使用 peripheral.call。

参数

  1. name string 要包装的外设名称。

返回值

  1. table | nil 包含外设方法的表；如果没有具有给定名称的外设，则返回 nil。

用法

  • 打开此计算机顶部的调制解调器。

    local modem = peripheral.wrap("top")
modem.open(1)
find(ty [, filter])Source

查找指定类型的所有外设，并返回已包装的外设。

参数

  1. ty string 要查找的外设类型。
  2. filter? function(name: string, wrapped: table):boolean 一个过滤函数，它接收外设的名称和包装后的表，并返回该项是否应包含在结果中。

返回值

  1. table... 0 个或多个符合给定过滤条件的已包装外设。

用法

  • 查找所有显示器并将它们存入一个表中，在每个显示器上写入“Hello”。

    local monitors = { peripheral.find("monitor") }
for _, monitor in pairs(monitors) do
  monitor.write("Hello")
end

  • 查找连接到此计算机的所有无线调制解调器。

    local modems = { peripheral.find("modem", function(name, modem)
    return modem.isWireless() -- Check this modem is wireless.
end) }

  • 这里滥用了 filter 参数来在每个调制解调器上调用 rednet.open。

    peripheral.find("modem", rednet.open)
