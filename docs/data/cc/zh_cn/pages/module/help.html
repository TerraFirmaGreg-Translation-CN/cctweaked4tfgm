path()Source

返回搜索帮助文件时使用的以冒号分隔的目录列表。所有目录均为绝对路径。

返回

  1. string 当前帮助搜索路径，以冒号分隔。

另见

  • help.setPath
setPath(newPath)Source

将搜索帮助文件时使用的以冒号分隔的目录列表设置为 newPath

参数

  1. newPath string 要使用的新路径。

用法

  • help.setPath( "/disk/help/" )
  • help.setPath( help.path() .. ":/myfolder/help/" )

另见

  • help.path
lookup(topic)Source

返回给定主题的帮助文件位置。

参数

  1. topic string 要查找的主题

返回

  1. string | nil 给定主题的帮助文件路径，如果找不到则为 nil。

用法

  • help.lookup("disk")

变更

  • 在 1.80pr1 版本中变更： 现在支持查找 .txt 文件。
  • 在 1.97.0 版本中变更： 现在支持查找 Markdown 文件。
topics()Source

返回可查找和/或显示的主题列表。

返回

  1. table 按字母顺序排列的主题列表。

用法

  • help.topics()
completeTopic(prefix)Source

返回与前缀匹配的主题结尾列表。可与 read 一起使用，以便输入帮助主题。

参数

  1. prefix string 要匹配的前缀

返回

  1. table 匹配的主题列表。

变更

  • 新增于版本 1.74
