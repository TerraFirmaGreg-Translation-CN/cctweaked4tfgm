turtle

海龟是一种机器人装置，可以破坏和放置方块、攻击生物并在世界中移动。它们有一个 16 格的内部物品栏，可用于存储它们已破坏或想要放置的方块。

移动

海龟能够在世界中移动。由于海龟本身是方块，它们受限于 Minecraft 的网格，一次只能移动一个方块。

turtle.forward 和 turtle.back 将海龟朝其面向的方向移动，而 turtle.up 和 turtle.down 则使其上下移动（正如人们所料！）。要向左或向右移动，首先需要使用 turtle.turnLeft/turtle.turnRight 转动海龟，然后向前或向后移动。

🛈 信息

“turtle”这一名称来自 海龟绘图，它起源于 Logo 编程语言。在其中，你会用“move 10”和“turn left”等各种命令来移动海龟，就像 ComputerCraft 的海龟一样！

移动海龟（但不包括转动它）会消耗 燃料。如果海龟没有任何燃料，它就不会移动，并且移动函数将返回 false。如果你的海龟一动不动，首先要检查的是你是否已经为海龟添加燃料。

处理错误

许多海龟函数可能以各种方式失败。例如，如果前方已经有方块，海龟就无法向前移动。可能失败的函数不会报错，而是在成功时返回 true，或在失败时返回 false 以及一些错误消息。

意外失败常常会导致奇怪的行为。通常最好检查这些函数的返回值，或将它们包装在 assert 中（例如，使用 assert(turtle.forward()) 而不是 turtle.forward()），以免程序出现异常行为。

海龟升级

虽然普通海龟可以在世界中移动并放置方块，但其功能有限。幸运的是，海龟可以通过升级进行升级。海龟有两个升级槽，分别位于左侧和右侧。可以通过将海龟与升级物品一起合成，或调用 turtle.equipLeft/turtle.equipRight 函数来装备升级。

默认情况下，任何钻石工具都可以用作升级（不过可以通过 数据包添加更多）。钻石镐可用于破坏方块（使用 turtle.dig），而剑可以攻击实体（turtle.attack）。其他工具有更小众的用途，例如锄可以耕地。

某些外设（即 扬声器以及末影和无线 调制解调器）也可以作为升级装备。之后可以通过访问 "left" 或 "right" 外设来使用它们。

craft([limit=64])Source

根据海龟的物品栏合成一个配方。海龟的物品栏应像合成网格一样摆放。例如，要合成木棍，槽位 1 和 5 应包含木板。所有其他槽位都应为空，包括合成“网格”之外的槽位。

turtle.craft(0) 可用于检查海龟是否包含有效配方，而不实际进行合成。

参数

  1. limit? number = 64 要运行的最大合成步骤数。

返回值

  1. true 如果合成成功。

或

  1. false 如果合成失败。
  2. string 描述合成失败原因的字符串。

抛出

  • 当 limit 小于 0 或大于 64 时。

refuel([count])Source

为这只海龟补充燃料。

虽然海龟可以执行的大多数操作（例如挖掘或放置方块）都是免费的，但移动会消耗海龟内部缓冲区的燃料。如果海龟没有燃料，它就不会移动。

refuel 为海龟补充燃料，消耗当前所选槽位中的燃料物品（例如煤炭或熔岩桶）并将其转化为能量。一旦海龟完全补充燃料或所有物品都已消耗完，此操作就会完成。

参数

  1. count? number 要消耗的最大物品数。可以通过0来检查物品是否可燃。

返回

  1. true 如果海龟已加油。

或

  1. false 如果海龟没有加油。
  2. string 海龟没有加油的原因。

抛出

  • 如果加油计数超出范围。

用法

  • 从当前选定的槽位给乌龟补充燃料。

    local level = turtle.getFuelLevel()
if level == "unlimited" then error("Turtle does not need fuel", 0) end

local ok, err = turtle.refuel()
if ok then
 local new_level = turtle.getFuelLevel()
 print(("Refuelled %d, current level is %d"):format(new_level - level, new_level))
else
 printError(err)
end

  • 检查当前项目是否是有效的燃料源。

    local is_fuel, reason = turtle.refuel(0)
if not is_fuel then printError(reason) end

equipLeft()Source

在海龟的左侧装备（或取消装备）一个物品。

这会在当前选定的插槽中找到该物品，并尝试将其装备到海龟的左侧。先前的升级将被移除并放入海龟的库存中。如果插槽中没有物品，则先前的升级将被删除，但不会装备新的。

返回

  1. true 如果装备了该物品。

或

  1. false 如果我们无法装备该物品。
  2. string 装备该物品失败的原因。

另请参阅

  • equipRight
  • getEquippedLeft

更改

  • 1.6 版本新增

inspect()Source

获取 有关海龟前面的块 的信息。

返回

  1. boolean 海龟前面是否有方块。
  2. table | string 前面的块的信息，或者说明没有块的消息。

用法

  • local has_block, data = turtle.inspect()
if has_block then
 print(textutils.serialise(data))
 -- {
 --   name = "minecraft:oak_log",
 --   state = { axis = "x" },
 --   tags = { ["minecraft:logs"] = true, ... },
 -- }
else
 print("No block in front of the turtle")
end

getItemDetail([slot [, detailed]])Source

获取有关给定槽中的项目的信息。

参数

  1. slot? number 要获取相关信息的插槽。默认为选定的插槽。
  2. detailed? boolean 是否包含“详细”信息。当 true 时，该方法将包含更多有关该项目的信息，但代价是运行时间更长。

返回

  1. 无 | table 有关此插槽中的项目的信息，如果为空，则为 nil。

抛出

  • 如果槽位超出范围。

用法

  • 打印当前槽位，假设它包含 13 个污垢。

    print(textutils.serialise(turtle.getItemDetail()))
-- => {
--  name = "minecraft:dirt",
--  count = 13,
-- }
