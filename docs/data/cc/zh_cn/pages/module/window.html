窗户

终端重定向占用现有终端较小的面积。这允许轻松定义显示器内可以写入/绘制的空间，然后根据需要重新绘制/重新定位/等等。 API 本身只包含一个函数，window.create，它返回窗口本身。

Windows 被视为终端对象 - 因此，它们可以访问术语 API 中的几乎所有命令（加上它们自己的一些额外命令，在所述 API 中列出），并且是重定向到的有效目标。

每个窗口都有一个“父”终端对象，它可以是计算机自己的显示器、监视器、另一个窗口甚至其他用户定义的终端对象。每当呈现一个窗口时，实际的屏幕写入都是通过该父级执行的（或者，如果该窗口也有一个，则通过该父级执行，依此类推）。请记住，在编写给定的子窗口时，父窗口的光标将因此四处移动等。

Windows 保留“通过”它们呈现的所有内容的内存（因此充当显示缓冲区），并且如果父级的显示被擦除，则稍后可以轻松地重绘窗口的内容。窗口也可以被标记为不可见，以防止对其进行任何更改，直到它再次被标记为可见。

父终端对象可以有多个分配给它的子对象，并且窗口可以重叠。例如，Multishell 系统通过为每个选项卡分配一个覆盖屏幕的窗口来运行，每个选项卡都使用起始终端显示作为其父级，并且一次只有其中一个可见。

create(parent, nX, nY, nWidth, nHeight [, bStartVisible])Source

返回一个终端对象，该对象是指定父终端对象中的一个空格。然后可以以与包装监视器相同的方式使用（甚至重定向到）它。请参阅 术语 API 以获取可用函数列表。

term 本身不能作为父级传递，但 term.native 是可以接受的。一般来说，term.current 或包装监视器将是最合适的，尽管窗口甚至可能将其他窗口指定为其父窗口。

参数

  1. parent term.Redirect 绘制到的父终端重定向。
  2. nX number 该窗口在父终端中绘制的 x 坐标
  3. nY number 该窗口在父终端中绘制的 y 坐标
  4. nWidth number 该窗口的宽度
  5. nHeight number 该窗口的高度
  6. bStartVisible? boolean 默认情况下此窗口是否可见。默认为 true。

返回

  1. Window 构造的窗口

用法

  • 创建一个较小的窗口，将其填充为红色并在其中写入一些文本。

    local my_window = window.create(term.current(), 1, 1, 20, 5)
my_window.setBackgroundColour(colours.red)
my_window.setTextColour(colours.white)
my_window.clear()
my_window.write("Testing my window!")

  • 创建一个较小的窗口并重定向到它。

    local my_window = window.create(term.current(), 1, 1, 25, 5)
term.redirect(my_window)
print("Writing some long text which will wrap around and show the bounds of this window.")

Window.reposition(new_x, new_y [, new_width, new_height [, new_parent]])Source

重新定位给定窗口或调整其大小。

此函数还接受参数来更改此窗口的大小。建议您在更改窗口后触发 term_resize 事件，以允许程序调整其大小。

参数

  1. new_x number 该窗口的新 x 位置。
  2. new_y number 该窗口的新 y 位置。
  3. new_width? number 此窗口的新宽度。
  4. new_height number 此窗口的新高度。
  5. new_parent? term.Redirect 此窗口应绘制到的新重定向对象。
