paintutils

用于绘制更复杂图形（如像素、线条和图像）的实用工具。

parseImage(image)Source

从多行字符串中解析图像

参数

  1. image string 包含原始图像数据的字符串。

返回值

  1. table 解析后的图像数据，适用于与 paintutils.drawImage 一起使用。

用法

  • 从字符串解析图像并绘制它。

    local image = paintutils.parseImage([[
 e  e

e    e
 eeee
]])
paintutils.drawImage(image, term.getCursorPos())

变更

  • 新增于版本 1.80pr1
loadImage(path)Source

从文件加载图像。

你可以使用 paint 程序创建适合加载的文件。

参数

  1. path string 要加载的文件。

返回值

  1. table | nil 解析后的图像数据，适用于与 paintutils.drawImage 一起使用；如果文件不存在，则为 nil。

用法

  • 加载图像并绘制它。

    local image = paintutils.loadImage("data/example.nfp")
paintutils.drawImage(image, term.getCursorPos())
drawPixel(xPos, yPos [, colour])Source

在指定位置向当前终端绘制单个像素。

⚠ 警告

此函数可能会改变光标位置和当前背景色。你不应期望这两者保持不变。

参数

  1. xPos number 要绘制的 x 位置，其中 1 为最左侧。
  2. yPos number 要绘制的 y 位置，其中 1 为最顶部。
  3. colour? number 此像素的 color。如果未指定，将使用当前背景色。
drawLine(startX, startY, endX, endY [, colour])Source

从起始位置到结束位置绘制一条直线。

⚠ 警告

此函数可能会改变光标位置和当前背景色。你不应期望这两者保持不变。

参数

  1. startX number 直线的起始 x 坐标。
  2. startY number 直线的起始 y 坐标。
  3. endX number 直线的结束 x 坐标。
  4. endY number 直线的结束 y 坐标。
  5. colour? number 此像素的 color。如果未指定，将使用当前背景色。

用法

  • paintutils.drawLine(2, 3, 30, 7, colors.red)

drawImage(image, xPos, yPos)Source

绘制由 paintutils.parseImage 或 paintutils.loadImage 加载的图像。

⚠ 警告

此函数可能会改变光标位置和当前背景色。你不应期望这两者保持不变。

参数

  1. image table 解析后的图像数据。
  2. xPos number 开始绘制的 x 坐标。
  3. yPos number 开始绘制的 y 坐标。

用法

  • 加载图像并绘制它。

    local image = paintutils.loadImage("data/example.nfp")
paintutils.drawImage(image, term.getCursorPos())
