pullEvent([filter])Source

暂停当前线程的执行，并等待任何匹配 filter 的事件。

此函数会让出当前进程，并等待通过可变参数列表恢复它，其中第一个元素匹配 filter。如果未提供 filter，则将匹配所有事件。

与 os.pullEventRaw 不同，它会在发生 “terminate” 事件时停止应用程序，并打印错误 “Terminated”。

参数

  1. filter? string 要过滤的事件。

返回值

  1. string event 已触发事件的名称。
  2. any param... 事件的可选附加参数。

用法

  • 监听 mouse_click 事件。

    while true do
    local event, button, x, y = os.pullEvent("mouse_click")
    print("Button", button, "was clicked at", x, ",", y)
end

  • 监听多个事件。

    while true do
    local eventData = {os.pullEvent()}
    local event = eventData[1]

    if event == "mouse_click" then
        print("Button", eventData[2], "was clicked at", eventData[3], ",", eventData[4])
    elseif event == "key" then
        print("Key code", eventData[2], "was pressed")
    end
end

另请参见

  • os.pullEventRaw 用于拉取 terminate 事件。

变更

  • 在 1.3 版本中变更： 添加了 filter 参数。
pullEventRaw([filter])Source

暂停当前线程的执行，并等待事件，包括 terminate 事件。

此函数的行为几乎与 os.pullEvent 相同，不同之处在于它允许你自己处理 terminate 事件——当按下 Ctrl+T 时程序不会停止执行。

参数

  1. filter? string 要过滤的事件。

返回值

  1. string event 已触发事件的名称。
  2. any param... 事件的可选附加参数。

用法

  • 监听 terminate 事件。

    while true do
    local event = os.pullEventRaw()
    if event == "terminate" then
        print("Caught terminate event!")
    end
end

另请参见

  • os.pullEvent 用于正常拉取事件。

run(env, path, ...)Source

使用指定的环境和参数运行给定路径下的程序。

此函数不会像命令行那样解析程序名称。这意味着，例如 os.run("edit") 将无法工作。此外，它不会在环境中提供对 shell API 的访问。若需要这种行为，请改用 shell.run。

如果找不到程序，或程序运行失败，它会打印错误并返回 false。如果你想更优雅地处理这种情况，请使用 loadfile 之类的替代方案。

参数

  1. env table 运行程序时使用的环境。
  2. path string 要运行的程序的确切路径。
  3. ... 要传递给程序的参数。

返回值

  1. boolean 程序是否运行成功。

用法

  • 在程序中运行默认命令行：

    os.run({}, "/rom/programs/shell.lua")

另请参见

  • shell.run
  • loadfile

startTimer(time)Source

启动一个将在指定秒数后运行的计时器。一旦计时器触发，一个 timer 事件将被添加到队列中，并将此函数返回的 ID 作为第一个参数。

与 sleep 一样，时间将自动向上取整到最接近的 0.05 秒的倍数，因为它会等待固定数量的世界刻。

参数

  1. time number 计时器触发前的秒数。

返回值

  1. number 新计时器的 ID。可用于过滤 timer 事件，或取消计时器。

抛出

  • 如果时间小于零。

另见

  • cancelTimer 用于取消计时器。

time([locale])Source

根据传入的字符串返回当前时间。该值始终在 [0.0, 24.0) 范围内。

  • 如果使用 ingame 调用，将返回当前世界时间。这是未传入任何内容时的默认值。
  • 如果使用 utc 调用，返回 UTC 时间中的当天小时。
  • 如果使用 local 调用，返回服务器所在时区中当天的小时。

此函数也可以使用从 date 返回的表来调用，这会将日期字段转换为 UNIX 时间戳（自 1970 年 1 月 1 日以来的秒数）。

参数

  1. locale? string | table 时间的区域设置，或由 os.date("*t") 填充的用于解码的表。如果未指定，则默认为 ingame 区域设置。

返回值

  1. any 所选区域设置的小时，或来自表的 UNIX 时间戳，取决于传入的参数。

抛出

  • 如果传入了无效的区域设置。

用法

  • 打印当前游戏内时间。

    textutils.formatTime(os.time())

另见

  • textutils.formatTime 用于将时间转换为用户可读的字符串。
  • date 用于获取可使用此函数转换的日期表。

变更

  • 1.2 版本新增
  • 在版本 1.80pr1 中已更改： 添加对获取本地时间和 UTC 时间的支持。
  • 在版本 1.82.0 中已更改： 参数现在不区分大小写。
  • 在版本 1.83.0 中已更改： time 现在接受表参数并将其转换为 UNIX 时间戳。
day([locale])Source

返回根据指定 locale 得到的天数。

  • 如果以 ingame 调用，则返回自世界创建以来的天数。这是默认行为。
  • 如果以 utc 调用，则返回 UTC 时区下自 1970 年 1 月 1 日以来的天数。
  • 如果以 local 调用，则返回服务器本地时区下自 1970 年 1 月 1 日以来的天数。

参数

  1. locale? string 要获取天数的 locale。如果未设置，则默认为 ingame。

返回值

  1. number 根据所选 locale 得到的天数。

抛出

  • 如果传入了无效的区域设置。

变更

  • 1.48 版本新增
  • 在版本 1.82.0 中已更改： 参数现在不区分大小写。
epoch([locale])Source

返回根据 locale 决定的、自某个纪元以来的毫秒数。

  • 如果以 ingame 调用，则返回自世界创建以来的 游戏内 毫秒数。这是默认行为。
  • 如果以 utc 调用，则返回 UTC 时区下自 1970 年 1 月 1 日以来的毫秒数。
  • 如果以 local 调用，则返回服务器本地时区下自 1970 年 1 月 1 日以来的毫秒数。
🛈 信息

ingame 时区假设一个 Minecraft 天由 86,400,000 毫秒组成。由于一个游戏内天比现实中的一天（20 分钟）快得多，因此它会比现实时间变化得更快——现实中的一秒等于 72000 游戏内毫秒。如果你想将此值转换为现实时间，请除以 72000；要转换为刻（其中一天为 24000 刻），请除以 3600。

参数

  1. locale? string 要获取毫秒数的 locale。如果未设置，则默认为 ingame。

返回值

  1. number 根据所选 locale 得到的自纪元以来的毫秒数。

抛出

  • 如果传入了无效的区域设置。

用法

  • 获取当前时间，并使用 date 将其转换为表。

    -- Dividing by 1000 converts it from milliseconds to seconds.
local time = os.epoch("local") / 1000
local time_table = os.date("*t", time)
print(textutils.serialize(time_table))

变更

  • 新增于版本 1.80pr1
date([format [, time]])Source

使用指定的格式字符串和可选的待格式化时间返回日期字符串（或表）。

格式字符串采用与 C 的 strftime 函数相同的格式。格式字符串还可以加上感叹号（!）前缀，以使用 UTC 时间而不是服务器本地时区。

如果格式恰好为 "*t"（或 "!*t" ），则改为返回时间戳的表表示。此表包含年、月、日、时、分、秒、星期几、一年中的第几天以及夏令时是否生效等字段。可以使用 time 将此表转换回时间戳。

参数

  1. format? string 要返回的字符串格式。默认为 %c，它会展开为类似于 "Sat Dec 24 16:58:00 2011" 的字符串。
  2. time? number 要转换为字符串的时间戳。默认为当前时间。

返回值

  1. any 格式化后的结果字符串或表。

抛出

  • 如果传入了无效格式。

用法

  • 以用户友好的字符串形式打印当前日期。

    os.date("%A %d %B %Y") -- See the reference above!

  • 将时间戳转换为表。

    os.date("!*t", 1242534247)
--[=[ {
 -- Date
 year  = 2009,
 month = 5,
 day   = 17,
 yday  = 137,
 wday  = 1,
 -- Time
 hour  = 4,
 min   = 24,
 sec   = 7,
 isdst = false,
} ]=]
