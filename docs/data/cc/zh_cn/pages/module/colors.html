colors

用于颜色值的常量和函数，适合与 term 和 redstone 配合使用。

这与来自 Project Red 等模组的 Bundled Cables，以及 高级计算机和高级显示器上的颜色 配合使用时很有用。

对于非美式英语版本，只需将 colors 替换为 colours。这个替代 API 完全相同，只是颜色使用英式英语（例如 colors.gray 拼写为 colours.grey）。

在基础终端（例如计算机和显示器）上，所有颜色都会转换为灰度。这意味着你仍然可以在屏幕上使用全部 16 种颜色，但它们会显示为最接近的灰色调。你可以使用函数 term.isColor 检查终端是否支持颜色。

灰度颜色通过取三个分量的平均值来计算，即 (red + green + blue) / 3。

combine(...)Source

将一组颜色（或颜色集合）合并为更大的集合。适用于 Bundled Cables。

参数

  1. ... number 要合并的颜色。

返回值

  1. number ... 中给出的颜色集合的并集

用法

  • colors.combine(colors.white, colors.magenta, colours.lightBlue)
-- => 13

变更

  • 1.2 版本新增
subtract(colors, ...)Source

从初始集合中移除一种或多种颜色（或颜色集合）。适用于 Bundled Cables。

第一个参数之后的每个参数可以是单一颜色，也可以是颜色集合（在后一种情况下，集合中的所有颜色都会从原始集合中移除）。

参数

  1. colors number 要从中减去的颜色。
  2. ... number 要减去的颜色。

返回值

  1. number 结果颜色。

用法

  • colours.subtract(colours.lime, colours.orange, colours.white)
-- => 32

变更

  • 1.2 版本新增
test(colors, color)Source

测试 color 是否包含在 colors 中。适用于 Bundled Cables。

参数

  1. colors number 一种颜色或颜色集合
  2. color number colors 应包含的一种颜色或颜色集合。

返回值

  1. boolean 如果 colors 包含 color 中的所有颜色。

用法

  • colors.test(colors.combine(colors.white, colors.magenta, colours.lightBlue), colors.lightBlue)
-- => true

变更

  • 1.2 版本新增
packRGB(r, g, b)Source

将三色 RGB 值合并为一个十六进制表示。

参数

  1. r number 红色通道，应介于 0 和 1 之间。
  2. g number 绿色通道，应介于 0 和 1 之间。
  3. b number 蓝色通道，应介于 0 和 1 之间。

返回值

  1. number 合并后的十六进制颜色。

用法

  • colors.packRGB(0.7, 0.2, 0.6)
-- => 0xb23399

变更

  • 1.81.0 版本新增
unpackRGB(rgb)Source

将十六进制 RGB 颜色分离为其三个组成通道。

参数

  1. rgb number 合并后的十六进制颜色。

返回值

  1. number 红色通道，将介于 0 和 1 之间。
  2. number 绿色通道，将介于 0 和 1 之间。
  3. number 蓝色通道，将介于 0 和 1 之间。

用法

  • colors.unpackRGB(0xb23399)
-- => 0.7, 0.2, 0.6

另见

  • colors.packRGB

变更

  • 1.81.0 版本新增

toBlit(color)Source

将给定颜色转换为 paint/blit 十六进制字符（0-9a-f）。

这等同于将 floor(log_2(color)) 转换为十六进制。超出有效颜色范围的值会报错。

参数

  1. color number 要转换的颜色。

返回值

  1. string 颜色的 blit 十六进制代码。

用法

  • colors.toBlit(colors.red)
-- => "c"

另见

  • colors.fromBlit

更改

  • 新增于版本 1.94.0
fromBlit(hex)Source

将给定的 paint/blit 十六进制字符（0-9a-f）转换为颜色。

这等同于将十六进制字符转换为数字，然后计算 2 ^ decimal

参数

  1. hex string 要转换的 paint/blit 十六进制字符

返回值

  1. number 颜色

用法

  • colors.fromBlit("e")
-- => 16384

另见

  • colors.toBlit

更改

  • 新增于版本 1.105.0
