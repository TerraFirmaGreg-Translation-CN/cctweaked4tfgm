commands

执行 Minecraft 命令，并从命令计算机的结果中收集数据。

🛈 注意

此 API 仅在命令计算机上可用。普通玩家无法访问。

虽然可以直接使用 commands.exec 来执行命令，但 commands API 还提供了用于执行每条命令的辅助方法。例如，commands.say("Hi!") 等同于 commands.exec("say Hi!")。

commands.async 提供了用于执行异步命令的类似接口。commands.async.say("Hi!") 等同于 commands.execAsync("say Hi!")。

用法

  • 将此计算机上方的方块设置为石头：

    commands.setblock("~", "~1", "~", "minecraft:stone")

exec(command)Source

执行特定命令。

参数

  1. command string 要执行的命令。

返回值

  1. boolean 命令是否成功执行。
  2. { string... } 此命令的输出，作为行列表。
  3. number | nil “受影响”对象的数量，如果命令失败则为 nil。其定义因命令而异。

用法

  • 将命令计算机上方的方块设置为石头。

    commands.exec("setblock ~ ~1 ~ minecraft:stone")

更改

  • 在 1.71 版本中更改： 添加了包含命令输出的返回值。
  • 在 1.85.0 版本中更改： 添加了包含受影响对象数量的返回值。
execAsync(command)Source

异步执行命令。

与 exec 不同，这会立即返回，而不是等待命令执行。这允许你同时运行多个命令。

当此命令执行完毕后，它会将一个 task_complete 事件加入队列，其中包含执行此命令的结果（即 exec 会返回的内容）。

参数

  1. command string 要执行的命令。

返回值

  1. number “任务 id”。当此命令执行后，它会将一个带有匹配 id 的 task_complete 事件加入队列。

用法

  • 异步将计算机上方的方块设置为石头。

    commands.execAsync("setblock ~ ~1 ~ minecraft:stone")

另请参阅

  • parallel 也可以使用 parallel API 一次运行多个命令。

getBlockInfos(minX, minY, minZ, maxX, maxY, maxZ [, dimension])Source

获取一系列方块的信息。

这会返回与 getBlockInfo 相同的信息，只是针对多个方块一次性返回。

方块按 y 层升序遍历，然后是 z 和 x——返回的表可以使用 x + z*width + y*width*depth + 1 进行索引。

参数

  1. minX number 要查询范围的起始 x 坐标。
  2. minY number 要查询范围的起始 y 坐标。
  3. minZ number 要查询范围的起始 z 坐标。
  4. maxX number 要查询范围的结束 x 坐标。
  5. maxY number 要查询范围的结束 y 坐标。
  6. maxZ number 要查询范围的结束 z 坐标。
  7. dimension? string 要查询的维度（例如 “minecraft:overworld”）。默认为当前维度。

返回值

  1. { table... } 每个方块的信息列表。

抛出

  • 如果坐标不在世界内。

  • 如果尝试获取超过 4096 个方块的信息。

用法

  • 打印计算机周围一个立方体内的所有方块。

    -- Get a 3x3x3 cube around the computer
local x, y, z = commands.getBlockPosition()
local min_x, min_y, min_z, max_x, max_y, max_z = x - 1, y - 1, z - 1, x + 1, y + 1, z + 1
local blocks = commands.getBlockInfos(min_x, min_y, min_z, max_x, max_y, max_z)

-- Then loop over all blocks and print them out.
local width, height, depth = max_x - min_x + 1, max_y - min_y + 1, max_z - min_z + 1
for x = min_x, max_x do
 for y = min_y, max_y do
   for z = min_z, max_z do
     print(("%d, %d %d => %s"):format(x, y, z, blocks[(x - min_x) + (z - min_z) * width + (y - min_y) * width * depth + 1].name))
   end
 end
end

更改

  • 1.76 版本新增
  • 在 1.99 版本中更改： 添加了 dimension 参数。
getBlockInfo(x, y, z [, dimension])Source

获取某个方块的一些基本信息。

返回的表包含与 方块详情 中列出的相同信息。如果该方块有方块实体，其 NBT 也会被返回。

参数

  1. x number 要查询方块的 x 坐标。
  2. y number 要查询方块的 y 坐标。
  3. z number 要查询方块的 z 坐标。
  4. dimension? string 要查询的维度（例如 “minecraft:overworld”）。默认为当前维度。

返回值

  1. table 给定方块的信息。

抛出

  • 如果坐标不在世界内，或当前未加载。

更改

  • 在 1.76 版本中更改： 在返回值中添加了方块状态信息
  • 在 1.99 版本中更改： 添加了 dimension 参数。
getEntities(selector)Source

获取所有匹配给定选择器的实体。

参数

  1. selector string 一个 实体选择器，例如 @p 或 @a。

返回值

  1. { table... } 所有匹配实体的信息列表。

抛出

  • 如果实体选择器无法解析。

用法

  • 打印命令计算机 10 格范围内所有实体的名称。

    for _, entity in ipairs(commands.getEntities("@e[distance=..10]")) do
 print(entity.displayName)
end

  • Entity details

nativeSource

内置 commands API，不包含任何生成的命令辅助函数

如果某个内置函数（例如 commands.list）已被命令覆盖，这可能会有用。

asyncSource

一个包含所有命令的异步包装器的表。

与 commands.execAsync 一样，这会返回已入队命令的“任务 id”。

用法

  • 异步将计算机上方的方块设置为石头。

    commands.async.setblock("~", "~1", "~", "minecraft:stone")

另请参阅
