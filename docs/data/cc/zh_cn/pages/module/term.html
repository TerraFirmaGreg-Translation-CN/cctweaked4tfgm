term

与计算机的终端或显示器交互，写入文本并绘制 ASCII 图形。

写入终端

在终端上能执行的最简单操作是显示（或写入）一些文本。这可以通过 term.write 方法完成。

term.write("Hello, world!")

写入文本时，这会推进光标，因此下一次调用 term.write 时，文本将紧接在上一段文本之后写入。

term.write("Hello, world!")
term.write("Some more text")

term.getCursorPos 和 term.setCursorPos 可用于手动更改光标的位置。

term.clear()

term.setCursorPos(1, 1) -- The first column of line 1
term.write("First line")

term.setCursorPos(20, 2) -- The 20th column of line 2
term.write("Second line")

term.write 是一个相对基础且底层的函数，不处理换行或自动换行等更高级的功能。如果你只想在屏幕上显示文本，可能应改用 print 或 write。

颜色

到目前为止，我们写入的都是黑白文本。不过，高级计算机还可以通过 term.setTextColour 和 term.setBackgroundColour 函数显示多种颜色的文本。

print("This text is white")
term.setTextColour(colours.green)
print("This text is green")

这些函数接受 colors API 中的任何常量。颜色组合可能会被接受，但只会显示单一颜色（通常遵循 colors.toBlit 的行为）。

write(text)Source

在当前光标位置写入 text，并将光标移动到文本末尾。

与 _G.write 和 print 等函数不同，这不会对文本换行——它只是将文本复制到当前终端行。

参数

  1. text string 要写入的文本。
scroll(y)Source

将所有位置向上（或向下）移动 y 个像素。

终端中的每个像素都将被其下方 y 个像素处的行替换。如果 y 为负数，则会改为从上方复制像素。

参数

  1. y number 要向上移动的行数。这可以是负数。

blit(text, textColour, backgroundColour)Source

将 text 写入终端，并使用指定的前景色和背景色。

与 write 一样，文本将写入当前光标位置，光标会移动到文本末尾。

textColour 和 backgroundColour 必须都是与 text 长度相同的字符串。每个字符表示一个十六进制数字，并会被转换为 CC 的某种颜色。例如，"a" 对应紫色。

参数

  1. text string 要写入的文本。
  2. textColour string 对应的文本颜色。
  3. backgroundColour string 对应的背景色。

抛出异常

  • 如果三个输入的长度不同。

用法

  • 以彩虹色打印“Hello, world!”

    term.blit("Hello, world!","01234456789ab","0000000000000")

另见

  • colors 有关颜色常量及其十六进制值的列表。

变更

  • 新增于版本 1.74
  • 在版本 1.80pr1 中更改： 标准计算机现在可以使用全部 16 种颜色，在屏幕上会转换为灰度显示。
setPaletteColour(...)Source

为特定颜色设置调色板。

ComputerCraft 的调色板系统允许你更改特定颜色的显示方式。例如，你可以让 colors.red 更红，方法是将它的调色板设置为 #FF0000。这并不会让你绘制更多颜色——屏幕上一次仍然限制为 16 种——但你可以更改使用的是哪些颜色。

参数

  1. index number 应更改其调色板的颜色。
  2. colour number 一个表示该颜色 RGB 值的 24 位整数。例如，整数 0xFF0000 对应颜色 #FF0000。

或

  1. index number 应更改其调色板的颜色。
  2. r number 红色通道的强度，介于 0 和 1 之间。
  3. g number 绿色通道的强度，介于 0 和 1 之间。
  4. b number 蓝色通道的强度，介于 0 和 1 之间。

用法

  • 将红色从默认的 #CC4C4C 更改为 #FF0000。

    term.setPaletteColour(colors.red, 0xFF0000)
term.setTextColour(colors.red)
print("Hello, world!")

  • 同上，但分别指定每个颜色通道。

    term.setPaletteColour(colors.red, 1, 0, 0)
term.setTextColour(colors.red)
print("Hello, world!")

另见

  • colors.unpackRGB 用于从 24 位格式转换为三个独立通道。
  • colors.packRGB 用于从三个独立通道转换为 24 位格式。

更改

  • 新增于版本 1.80pr1

redirect(target)Source

将终端输出重定向到显示器、window或任何其他自定义终端对象。执行重定向后，任何对“term”函数的调用——或对使用 term 函数的函数的调用，如 print ——都将改为使用新的终端对象进行操作。

“终端对象”只是一个表，其中包含与 term 表中函数具有相同名称和一般特性的函数。例如，包装后的显示器就是合适的对象。

可以通过指回之前的终端对象来撤销重定向（每次切换时此函数都会返回该对象）。

参数

  1. target Redirect term API 将绘制到的终端重定向对象。

返回

  1. Redirect 之前的重定向对象，由 term.current 返回。

用法

  • 重定向到计算机右侧的显示器。

    term.redirect(peripheral.wrap("right"))

更改

  • 1.31 版本新增

native()Source

获取当前计算机的原生终端对象。

除非绝对必要，否则建议不要使用此函数。在多任务环境中，term.native 将不会是当前终端对象，因此绘制可能会干扰其他程序。

返回

  • 以彩虹色打印“Hello, world!”

    term.blit("Hello, world!","01234456789ab","0000000000000")

Redirect.setPaletteColour(...)Source

为特定颜色设置调色板。

ComputerCraft 的调色板系统允许你更改特定颜色的显示方式。例如，你可以让 colors.red 更红，方法是将它的调色板设置为 #FF0000。这并不会让你绘制更多颜色——屏幕上一次仍然限制为 16 种——但你可以更改使用的是哪些颜色。

参数

  1. index number 应更改其调色板的颜色。
  2. colour number 一个表示该颜色 RGB 值的 24 位整数。例如，整数 0xFF0000 对应颜色 #FF0000。

或

  1. index number 应更改其调色板的颜色。
  2. r number 红色通道的强度，介于 0 和 1 之间。
  3. g number 绿色通道的强度，介于 0 和 1 之间。
  4. b number 蓝色通道的强度，介于 0 和 1 之间。

用法

  • 将红色从默认的 #CC4C4C 更改为 #FF0000。

    term.setPaletteColour(colors.red, 0xFF0000)
term.setTextColour(colors.red)
print("Hello, world!")

  • 同上，但分别指定每个颜色通道。

    term.setPaletteColour(colors.red, 1, 0, 0)
term.setTextColour(colors.red)
print("Hello, world!")

另见

  • colors.unpackRGB 用于从 24 位格式转换为三个独立通道。
  • colors.packRGB 用于从三个独立通道转换为 24 位格式。

更改

  • 新增于版本 1.80pr1
