get(...)Source

向给定 URL 发起 HTTP GET 请求。

参数

  1. url string 要请求的 URL
  2. headers? { [string] = string } 作为此请求的一部分发送的额外标头。
  3. binary? boolean = false 响应句柄是否应以二进制模式打开，这意味着 read() 将返回数字而不是字符串。此选项用于与旧程序向后兼容，不建议在新代码中使用。

或

  1. request { url = string, headers? = { [string] = string }, binary? = boolean, method? = string, redirect? = boolean, timeout? = number } 请求的选项。有关这些选项的行为详情，请参见 http.request。

返回

  1. Response 生成的 HTTP 响应，可从其中读取。

或

  1. nil 当 HTTP 请求失败时，例如发生 404 错误或连接超时时。
  2. string 详细说明请求失败原因的消息。
  3. Response | nil 失败的 HTTP 响应（如果可用）。

用法

  • 向 example.tweaked.cc 发起请求，并打印返回的页面。

    local request = http.get("https://example.tweaked.cc")
print(request.readAll())
-- => HTTP is working!
request.close()

  • 在版本 1.80pr1 中变更： 现在出错时会在可用的情况下返回响应句柄。
  • 在版本 1.80pr1 中变更： 添加了用于二进制句柄的参数。
  • 在版本 1.80pr1.6 中变更： 添加了对表参数的支持。
  • 在版本 1.86.0 中变更： 添加了 PATCH 和 TRACE 方法。
  • 在版本 1.105.0 中变更： 添加了对自定义超时的支持。
  • 在版本 1.109.0 中变更： 返回的响应现在以原始字节读取正文，而不是从 UTF-8 解码。
  • 在版本 1.121.0 中变更： 放宽了 HTTP 动词验证，以允许任何匹配 [A-Z_-]{1,32} 的内容。

request(...)Source

异步向给定 URL 发起 HTTP 请求。

此函数会立即返回；请求完成后，将排队一个 http_success 或 http_failure。

参数

  1. url string 要请求的 URL
  2. body? string 可选字符串，包含请求的正文。如果指定，则将改为发起 POST 请求。
  3. headers? { [string] = string } 作为此请求的一部分发送的额外标头。
  4. binary? boolean = false 响应句柄是否应以二进制模式打开，这意味着 read() 将返回数字而不是字符串。此选项用于与旧程序向后兼容，不建议在新代码中使用。

或

  1. request { url = string, body? = string, headers? = { [string] = string }, binary? = boolean, method? = string, redirect? = boolean, timeout? = number }

    请求的选项。

    此表形式是先前语法的扩展版本。上面的所有参数都改为作为字段传入（例如，http.request("https://example.com") 变为 http.request { url = "https://example.com" }）。此表还接受几个额外选项：

    • method：要使用的 HTTP 方法，例如 "PATCH" 或 "DELETE"。
    • redirect：是否跟随 HTTP 重定向。默认为 true。
    • timeout：连接超时，以秒为单位。

另请参见

  • http.get 用于以同步方式发起 GET 请求。
  • http.post 用于以同步方式发起 POST 请求。

变更

  • 在版本 1.63 中变更： 添加了 headers 参数。
  • 在版本 1.80pr1 中变更： 添加了用于二进制句柄的参数。
  • 在版本 1.80pr1.6 中变更： 添加了对表参数的支持。
  • 在版本 1.86.0 中变更： 添加了 PATCH 和 TRACE 方法。
  • 在版本 1.105.0 中变更： 添加了对自定义超时的支持。
  • 在版本 1.109.0 中变更： 返回的响应现在以原始字节读取正文，而不是从 UTF-8 解码。
  • 在版本 1.121.0 中变更： 放宽了 HTTP 动词验证，以允许任何匹配 [A-Z_-]{1,32} 的内容。
checkURLAsync(url)Source

异步确定是否可以请求某个 URL。

如果此函数返回 true，还应监听 http_check，其中将包含有关该 URL 是否被允许的更多信息。

参数

  1. url string 要检查的 URL。

返回值

  1. true 当此 URL 并非无效时。这并不意味着它被允许——请参见上面的注释。

或

  1. false 当此 URL 无效时。
  2. string 此 URL 无效的原因（例如，格式错误或被阻止）。

另请参见

  • http.checkURL 用于同步版本。
checkURL(url)Source

确定是否可以请求某个 URL。

如果此函数返回 true，还应监听 http_check，其中将包含有关该 URL 是否被允许的更多信息。

参数

  1. url string 要检查的 URL。

返回值

  1. true 当此 URL 有效且可通过 http.request 请求时。

或

  1. false 当此 URL 无效时。
  2. string 此 URL 无效的原因（例如，格式错误或被阻止）。

用法

  • print(http.checkURL("https://example.tweaked.cc/"))
-- => true
print(http.checkURL("http://localhost/"))
-- => false Domain not permitted
print(http.checkURL("not a url"))
-- => false URL malformed

另请参见

  • http.checkURLAsync 用于异步版本。

或

另请参见

  • websocket_success
  • websocket_failure

websocket(...)Source

打开一个 websocket。

参数

  1. url string 要连接的 websocket URL。其协议应为 ws:// 或 wss://。
  2. headers? { [string] = string } 作为初始 websocket 连接的一部分发送的额外标头。

或

  1. request { url = string, headers? = { [string] = string }, timeout? = number }

    websocket 的选项。

    此表形式是先前语法的扩展版本。上面的所有参数改为作为字段传入（例如，http.websocket("https://example.com") 变为 http.websocket { url = "https://example.com" }）。此表还接受以下附加选项：

    • timeout：连接超时，以秒为单位。

返回值

  1. Websocket websocket 连接。

或

  1. false 如果 websocket 连接失败。
  2. string 描述连接失败原因的错误消息。

用法

  • 连接到回显 websocket 并发送消息。

    local ws = assert(http.websocket("wss://example.tweaked.cc/echo"))
ws.send("Hello!") -- Send a message
print(ws.receive()) -- And receive the reply
ws.close()

变更

  • 新增于版本 1.80pr1.1
  • 在版本 1.80pr1.3 中更改： 不再异步。
  • 在版本 1.95.3 中变更： 将 User-Agent 添加到默认标头。
  • 在版本 1.105.0 中变更： 添加了对表参数和自定义超时的支持。
  • 在版本 1.109.0 中变更： 非二进制 websocket 消息现在使用原始字节，而不是使用 UTF-8。

类型

Response

一个 HTTP 响应。它提供与 file 相同的方法，但提供若干请求特定的方法。

另请参阅

  • http.request 有关如何发起 HTTP 请求的说明。
Response.getResponseCode()Source

返回服务器返回的响应代码和响应消息。

返回值

  1. number 响应代码（即 200）
  2. string 响应消息（即 “OK”）

更改

  • 在版本 1.80pr1.13 中更改： 添加了响应消息返回值。
Response.getResponseHeaders()Source

获取一个包含响应头的表，其格式类似于 http.request 所需的格式。如果发送了多个同名头，它们将用逗号合并。

返回值

  1. { [string] = string } 响应头。

用法

  • 向 example.tweaked.cc 发起请求，并打印返回的头。

    local request = http.get("https://example.tweaked.cc")
print(textutils.serialize(request.getResponseHeaders()))
-- => {
--  [ "Content-Type" ] = "text/plain; charset=utf8",
--  [ "content-length" ] = 17,
--  ...
-- }
request.close()

Websocket

一个 websocket，可用于与 Web 服务器发送和接收消息。

另请参阅

  • http.websocket 有关如何打开 websocket 的说明。
Websocket.receive([timeout])Source

等待来自服务器的消息。

参数

  1. timeout? number 未收到消息时等待的秒数。

返回值

  1. string 收到的消息。
  2. boolean 如果这是二进制消息。

或者

  1. nil 如果 websocket 在等待期间关闭，或者如果超时。
  2. string 我们未能接收消息的原因。要么是 websocket 关闭的原因（由 websocket_closed 返回），要么是字符串 "Timed out"。

抛出

  • 如果 websocket 已关闭。

更改

  • 在版本 1.80pr1.13 中更改： 添加了指示消息是否为二进制的返回值。
  • 在版本 1.87.0 中更改： 添加了 timeout 参数。
  • 在版本 1.117.0 中更改： 添加了指示接收消息失败原因的返回值。
Websocket.send(message [, binary])Source

向已连接的服务器发送 websocket 消息。

参数

  1. message string 要发送的消息。
  2. binary? boolean 此消息是否应被视为二进制消息。

抛出

  • 如果消息过大。

  • 如果 websocket 已关闭。

更改

  • 在版本 1.81.0 中更改： 添加了用于二进制模式的参数。
Websocket.close()Source

关闭此 websocket。这将终止连接，意味着无法再通过它发送或接收消息。

Websocket.getResponseHeaders()Source

获取一个包含握手响应中头的表，其格式类似于 http.request 所需的格式。如果发送了多个同名头，它们将用逗号合并。

返回值

  1. { [string] = string } 响应头。

用法

  • 与 example.tweaked.cc 建立 websocket 连接，并打印返回的头。

    local ws = http.websocket("wss://example.tweaked.cc/echo")
print(textutils.serialize(ws.getResponseHeaders()))
-- => {
--  Connection = "Upgrade",
--  Upgrade = "websocket",
--  ...
-- }
ws.close()

更改

  • 新增于版本 1.117.0
