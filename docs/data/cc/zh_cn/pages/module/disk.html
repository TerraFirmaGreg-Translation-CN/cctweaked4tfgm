disk

与磁盘驱动器交互。

这些函数可操作本地连接的或远程的磁盘驱动器。要使用本地连接的驱动器，请将“side”指定为六个侧面之一（例如 left）；要使用远程磁盘驱动器，请指定启用其调制解调器时打印的名称（例如 drive_0）。

提示

所有计算机（命令计算机除外）、海龟和便携式计算机都可以放入磁盘驱动器中，以便像磁盘一样访问其内部存储。

isPresent(name)Source

检查磁盘驱动器中是否有任何物品

参数

  1. name string 磁盘驱动器的名称。

返回值

  1. boolean 如果磁盘驱动器中有物品。

用法

  • disk.isPresent("top")
getLabel(name)Source

获取给定磁盘驱动器内软盘、唱片或其他介质的标签。

如果驱动器内有计算机或海龟，这会将标签设置为 os.getComputerLabel 所读取的标签。

参数

  1. name string 磁盘驱动器的名称。

返回值

  1. string | nil 当前介质的名称；如果驱动器不存在或为空，则为 nil。

另见

  • disk.setLabel
setLabel(name, label)Source

设置软盘或其他介质的标签

参数

  1. name string 磁盘驱动器的名称。
  2. label string | nil 磁盘的新标签
hasData(name)Source

检查当前磁盘是否提供挂载。

对于磁盘和计算机会返回 true，但对于唱片不会。

参数

  1. name string 磁盘驱动器的名称。

返回值

  1. boolean 如果磁盘存在并提供挂载。

另见

  • disk.getMountPath
getMountPath(name)Source

查找本地计算机上可找到当前软盘（或其他挂载）内容的目录名称。

参数

  1. name string 磁盘驱动器的名称。

返回值

  1. string | nil 挂载的目录；如果驱动器不包含软盘或计算机，则为 nil。

另见

  • disk.hasData
hasAudio(name)Source

当前磁盘是否是 音乐磁盘，而不是软盘或其他物品。

如果返回 true，你就可以 播放 唱片。

参数

  1. name string 磁盘驱动器的名称。

返回值

  1. boolean 如果磁盘存在并且其上保存有音频。
getAudioTitle(name)Source

获取驱动器中音乐唱片的音轨标题。

对于唱片，这通常返回与 disk.getLabel 相同的内容。

参数

  1. name string 磁盘驱动器的名称。

返回值

  1. string | false | nil 音轨标题；如果驱动器中不是音乐唱片，则为 false；如果驱动器不存在，则为 nil。
playAudio(name)Source

开始播放驱动器中的音乐唱片。

如果任何磁盘驱动器上已有唱片正在播放，它会在目标驱动器开始播放前停止。当唱片到达音轨末尾、从驱动器中被取出、调用 disk.stopAudio，或开始播放另一张唱片时，唱片会停止。

参数

  1. name string 磁盘驱动器的名称。

用法

  • disk.playAudio("bottom")
stopAudio(name)Source

停止播放驱动器中的音乐唱片（如果它是通过 disk.playAudio 启动的）。

参数

  1. name string 磁盘驱动器的名称。
eject(name)Source

弹出驱动器中当前存在的任何物品，使其作为掉落物掉入世界中。

参数

  1. name string 磁盘驱动器的名称。

用法

  • disk.eject("bottom")
getID(name)Source

返回一个唯一标识驱动器中磁盘的数字。

注意，与 disk.getLabel 不同，对于其他介质（例如计算机或海龟），这不会返回任何内容。

参数

  1. name string 磁盘驱动器的名称。

返回值

  1. string | nil 磁盘 ID；如果驱动器不包含软盘，则为 nil。
