区块详细信息

CC: Tweaked 中的几个函数，例如 turtle.inspect 和 commands.getBlockInfo 提供了一种获取世界中某个方块信息的方法。本页详细介绍了 CC: Tweaked 可能返回的块的信息。

基本信息

块信息将始终包含：

  • name: string：该块的命名空间 ID，例如minecraft:dirt。请参阅 Minecraft wiki 以获取普通方块 ID 列表。
  • state: { [string] = any}：包含块的块状态的表。

例子

一块完全水化的农田：

{
    name = "minecraft:farmland",
    state = {
        moisture = 7
    }
}

伸出的活塞，面朝上：

{
    name = "minecraft:piston",
    state = {
        facing = "up",
        extended = true
    }
}

块标签

块具有的 tags。

  • tags: { [string] = boolean }：该块的标签集。这是标签名称到 true 的映射。

虽然标签的表示比单个列表稍微复杂一些，但这使得检查块是否具有特定标签变得非常容易：

--- Check if the block in front of the turtle is a log.
local function is_log()
    local ok, block = turtle.inspect()
    return ok and block.tags["minecraft:logs"]
end

例子

一块完全水化的农田：

{
    name = "minecraft:farmland",
    state = { ... },
    tags = {
        ["minecraft:mineable/shovel"] = true,
    }
}

地图颜色

块将出现在地图上的颜色（如果指定）。

  • mapColour?: number：块的颜色，以 RGB 十六进制值表示。
  • mapColor?: number：块的颜色，以 RGB 十六进制值表示。

地图颜色仅作为普通数字返回（例如 9923917 表示农田）。它可以使用 string.format 以十六进制显示，也可以使用 colors.unpackRGB 转换为单独的 RGB 值。

例子

一块完全水化的农田：

{
    name = "minecraft:farmland",
    state = { ... },
    mapColour = 9923917,
    mapColor = 9923917,
}
