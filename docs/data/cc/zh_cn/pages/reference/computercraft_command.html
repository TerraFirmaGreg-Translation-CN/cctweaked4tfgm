/computercraft 命令

CC: Tweaked 为服务器所有者提供了一个 /computercraft 命令，用于管理服务器上正在运行的计算机。

权限

由于 /computercraft 命令主要用于调试和管理目的，因此它的子命令通常要求您具有 op （或类似命令）。

  • 所有玩家都可以访问 queue 子命令。
  • 在多人服务器上，所有其他命令都需要 op。
  • 在单人游戏世界中，即使未启用作弊功能，玩家也可以运行 dump、turn-on/shutdown 和 track 子命令。 tp 和 view 命令需要作弊。

如果安装了 LuckPerms 等权限模块1，则可以配置对各个子命令的访问。每个子命令都会创建一个computercraft.command.NAME权限节点来控制哪些玩家可以执行它。

计算机选择器

某些命令（例如 tp 或 turn-on 目标是特定计算机或计算机列表。要指定在哪些计算机上运行，​​必须使用“计算机选择器”。

计算机选择器类似于 Minecraft 的实体目标选择器，但以计算机为目标。它们允许您根据一组谓词选择一台或多台计算机。

支持以下谓词：

  • id=<id>：选择具有特定 ID 的计算机。
  • instance=<id>：选择具有给定实例 ID 的计算机。
  • family=<normal|advanced|command>：根据计算机类型选择计算机。
  • label=<label>：选择具有给定标签的计算机。
  • distance=<distance>：选择执行命令的玩家特定距离内的计算机。这使用 Minecraft 的 float range 语法。

#<id> 也可以用作 @c[id=<id>] 的简写，以选择具有特定 ID 的计算机。

示例：

  • /computercraft turn-on #12：打开 ID 为 12 的计算机。
  • /computercraft shutdown @c[distance=..100]：关闭播放器100块的所有计算机。

命令

/computercraft dump

/computercraft dump 打印当前加载的计算机的表格，包括它们的 ID、位置以及它们是否正在运行。它还可以与单个计算机参数一起运行，以转储有关计算机的更多详细信息。

在计算机 ID 旁边，有几个按钮可用于 传送 到计算机，或 打开其终端 。

计算机按照与玩家的距离排序，因此附近的计算机会更早出现。

/computercraft turn-on [computers...]

打开一台或多台计算机，或者如果不带任何参数运行，则打开所有已加载的计算机。

示例

  • /computercraft turn-on #0 #2：打开 ID 为 0 和 2 的计算机。
  • /computercraft turn-on @c[family=command]：打开所有命令计算机。

/computercraft shutdown [computers...]

关闭一台或多台计算机，或者如果没有无参数运行，则关闭所有已加载的计算机。

这有时在处理延迟时很有用，可以作为确保 ComputerCraft 不会造成问题的一种方法。

示例

  • /computercraft shutdown：关闭所有已加载的计算机。
  • /computercraft shutdown @c[distance=..10]：关闭区块半径内的所有计算机。

/computercraft tp [computer]

传送到给定的计算机。

这通常通过 dump 命令接口使用，而不是直接调用。

/computercraft view [computer]

打开指定计算机的终端。这允许远程查看计算机而无需与块交互。

这通常通过 dump 命令接口使用，而不是直接调用。

/computercraft track

/computercraft track 命令允许您启用计算机分析。当计算机运行代码或与 Minecraft 世界交互时，我们会计算所需的时间。然后可以查询该计时信息，并将其用于查找可能导致延迟的计算机。

要启用探查器，请运行 /computercraft track start。然后计算机将开始记录指标。收集到足够的数据后，运行 /computercraft track stop 以停止分析并显示记录的数据。

默认情况下，该表显示每台计算机运行的次数以及运行时间（总计和平均）。在上面的截图中，我们可以看到其中一台计算机表现得特别糟糕，运行了7秒。这些按钮可用于传送到计算机，或打开其终端，并进一步检查它。

/computercraft track dump 可用于在任何时候显示此表（包括在分析仍在运行时）。

计算机还记录其他信息，例如它们消耗了多少服务器线程时间，或者它们的 HTTP 带宽使用情况。 dump 子命令接受要显示的其他字段的列表，而不是默认计时。

示例

  • /computercraft track dump server_tasks_count server_tasks：打印每台计算机执行的服务器线程任务的数量，以及它们总共花费的时间。
  • /computercraft track dump http_upload http_download：打印每台计算机上传和下载的字节数。

/computercraft queue

queue 子命令允许非管理员玩家排队 computer_command 事件到 命令计算机上。

这与普通的 /trigger 命令具有类似的目的。命令计算机可以选择监听此事件，然后执行某些操作。
