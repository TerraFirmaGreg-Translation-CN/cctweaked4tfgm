数据包

CC：Tweaked 允许通过数据包自定义和扩展其许多功能，例如向 ROM 添加新程序，或提供新的海龟工具。此页面用作 CC:T 数据包功能的参考。

🛈 数据包兼容性

与本文档的其他部分不同，数据包的格式在 Minecraft 版本之间发生变化。确保您使用适合您的 Minecraft 版本的正确文档。

  • 我的世界 1.20.1
  • 我的世界 1.21.1
  • 我的世界 26.3

除了本文档之外，我们还提供在线数据包构建器和示例/模板数据包。

CraftOS ROM

数据包可用于添加或覆盖 CraftOS ROM 中的文件，允许您添加新程序或模块，或调整现有程序或模块的行为。文件应放置在data/computercraft/lua/rom中。例如，包含data/computercraft/lua/rom/programs/example.lua的数据包将添加一个新程序example。

⚠ 文件命名

数据包对文件名施加了一些限制。因此，所有文件和目录名都必须小写。

  • rom/autorun 下的文件将在计算机启动时运行。
  • rom/modules/main下的文件可以通过require加载。
  • 位于 rom/apis/ 中的文件将在启动时通过 os.loadAPI 加载。同样：
    • 如果启用 HTTP API，将加载 rom/apis/http 下的文件。
    • rom/apis/turtle 下的文件将加载到所有海龟上。
    • rom/apis/pocket 下的文件将加载到所有袖珍计算机上。
    • rom/apis/command 下的文件将加载到所有命令计算机上。

标签

CC:T 提供了多个 block 和 item 标签。虽然大多数标签仅用于对相关块/项目进行分组（例如 computercraft:turtles 是所有海龟的列表），但有几个标签可以通过数据包进行扩展以调整功能：

  • computercraft:turtle_can_place 物品标签：此标签列出了海龟可以与 turtle.place 一起使用的物品。默认情况下，其中包含玻璃瓶和船，
  • computercraft:turtle_can_use 块标签：此标签列出了海龟可以与 turtle.place 交互的块。默认情况下，其中包含蜂箱、大锅和堆肥器。 数据包构建器具有将控制杆/按钮和调制解调器添加到此列表的选项，允许海龟切换它们。
  • computercraft:always_breakable 方块标签：所有海龟工具都能够破坏即时破坏方块，例如树苗。该标签指定可以被所有工具破坏的附加块。默认情况下，这包括树叶、竹子和竹树苗。
  • computercraft:turtle_shovel_harvestable、computercraft:turtle_sword_harvestable、computercraft:turtle_hoe_harvestable块标签：这些标签分别指定哪些块可以被铲子、剑和锄头打破。
