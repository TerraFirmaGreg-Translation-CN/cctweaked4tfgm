实体详情

CC: Tweaked 中的一些函数（例如 commands.getEntities）提供了一种获取有关实体的信息的方法。此页面详细介绍了 CC: Tweaked 可能返回的实体的信息。

基本信息

实体信息将始终包含：

  • name: string：该实体的命名空间 ID，例如minecraft:player。有关普通实体 ID 的列表，请参阅 Minecraft wiki。

例子

爬行者：

{
    name = "minecraft:creeper",
    count = 32,
}

显示信息

实体的显示名称。

  • displayName: string：实体的翻译显示名称。这使用服务器的语言。在多人游戏服务器上通常为英语，在单人游戏服务器上通常为您当前的语言。

例子

爬行者：

{
    name = "minecraft:creeper",
    displayName = "Creeper",
}

健康

实体的健康状况。

  • health: number：实体的当前健康状况。
  • maxHealth: number：实体的最大生命值。

例子

处于最大生命值的玩家。

{
    name = "minecraft:player",
    displayName = "Alex",
    health = 20,
    maxHealth = 20,
}

实体标签

该类型实体具有的标签。

  • tags: { [string] = boolean }：该实体的标签集。这是标签名称到 true 的映射。
