CC 中的 Lua 5.2/5.3 功能：调整

CC：Tweaked 基于 Cobalt Lua 运行时，它使用 Lua 5.2。但是，Cobalt 和 CC:T 实现了 Lua 5.2 和 5.3 中的附加功能（以及一些已弃用的 5.0 和 5.1 功能）。此页面列出了这些较新版本的所有兼容性。

路亚5.2

特征支持吗？笔记
goto/标签✔
_ENV✔
\z 逃脱✔
\xNN 逃脱✔
十六进制文字小数/指数部分✔
空语句✔
__len 元方法✔
__ipairs 元方法❌在 Lua 5.3 中已弃用。 ipairs 使用 __len/__index 代替。
__pairs 元方法✔
bit32 图书馆✔
collectgarbage isrunning、分代、增量选项❌CC:T 中不存在 collectgarbage。
新的 load 语法✔
loadfile 模式参数✔支持 5.1 和 5.2+ 语法。
已删除 loadstring❌
已删除 getfenv、setfenv🔶仅支持具有 _ENV 上值的闭包。
rawlen 功能✔
select 的负索引✔
已删除 unpack❌
xpcall 的参数✔
来自 coroutine.running 的第二个返回值✔
已删除 module✔
package.loaders -> package.searchers❌
加载器函数的第二个参数✔
package.config✔
package.searchpath✔
已删除 package.seeall✔
string.dump 具有上值的函数（将其删除）❌不支持 string.dump
string.rep 分隔符✔
%g 比赛组❌
删除 %z 匹配组❌
已删除 table.maxn❌
table.pack/table.unpack✔
math.log 基本参数✔
已删除 math.log10❌
*L 模式至 file:read✔
os.execute 退出类型+返回值❌CC:T 中不存在 os.execute。
os.exit 接近论证❌CC:T 中不存在 os.exit。
istailcall 字段位于 debug.getinfo 中❌
nparams 字段位于 debug.getinfo 中✔
isvararg 字段位于 debug.getinfo 中✔
debug.getlocal 可变参数的负索引❌
debug.getuservalue/debug.setuservalue❌用户数据在 CC:T 中很少使用，因此没有必要。
debug.upvalueid✔
debug.upvaluejoin✔
尾部调用挂钩❌
= 块前缀✔
C 边界的产量✔
消除歧义错误✔
标识符可能不再使用与区域设置相关的字母✔
星历表❌
相同的功能可以重复使用❌Lua 5.4 中删除
分代垃圾收集器❌Cobalt 使用内置的 Java 垃圾收集器。

路亚5.3

特征支持吗？笔记
整数子类型❌
位运算符/取整除法❌
\u{XXX} 转义序列✔
utf8 图书馆✔
删除了 __ipairs 元方法✔
coroutine.isyieldable✔
string.dump 剥离参数✔
string.pack/string.unpack/string.packsize✔
table.move✔
math.atan2 -> math.atan🔶math.atan 支持其两个参数形式。
删除了 math.frexp、math.ldexp、math.pow、math.cosh、math.sinh、math.tanh❌
math.maxinteger/math.mininteger❌
math.tointeger❌
math.type❌
math.ult❌
已删除 bit32 库❌
移除 *（来自 file:read 模式）✔
table.*、ipairs 中遵循的元方法✔

路亚5.5

特征支持吗？笔记
table.create✔
utf8.offset 返回结束位置✔

路亚5.0

特征支持吗？笔记
arg 表🔶仅在 shell 中设置 - 不在函数中使用。
string.gfind✔等于string.gmatch。
table.getn✔等于#tbl。
table.setn❌
math.mod✔等于math.fmod。
table.foreach/table.foreachi✔
gcinfo❌Cobalt 使用内置的 Java 垃圾收集器。
