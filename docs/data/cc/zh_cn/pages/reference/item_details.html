商品详情

CC: Tweaked 中的几个函数，例如 turtle.getItemDetail 和 inventory.getItemDetail 提供了一种获取有关项目堆栈信息的方法。本页详细介绍了 CC: Tweaked 可能返回的物品的信息。

某些方法（例如 inventory.list 和 turtle.getItemDetail，在未设置 detailed 标志时）只会返回物品的“基本信息”。

基本信息

项目信息将始终包含：

  • name: string：此项的命名空间 ID，例如minecraft:dirt。请参阅 Minecraft wiki 以获取原始项目 ID 列表。
  • count: number：堆栈中的项目数。
  • nbt?: string：堆栈中NBT的哈希值。虽然这不会暴露有关该物品的 NBT 的任何信息，但它可以用作比较物品的一种方式。如果两个物品具有相同的 name 和 nbt，则所有其他属性（例如耐用性、结界）将相同。

例子

一堆 32 根去皮金合欢原木：

{
    name = "minecraft:stripped_acacia_log",
    count = 32,
}

附带升级的乌龟：

{
    name = "computercraft:turtle_normal",
    count = 1,
    nbt = "a33095c2eb17c10e12f2b970c4e1b2bb",
}

显示信息

项目工具提示中显示的常见信息：

  • displayName: string：项目的翻译显示名称。这使用服务器的语言。在多人游戏服务器上通常为英语，在单人游戏服务器上通常为您当前的语言。
  • lore: { string... }：关于此项目的附加知识，作为字符串列表。

例子

一堆去皮的金合欢原木：

{
    name = "minecraft:stripped_acacia_log",
    count = 32,
    displayName = "Stripped Acacia Log",
}

最大计数

该物品可以堆叠的最大物品数量：

  • maxCount: number：项目堆栈的最大可能大小。

例子

一堆去皮的金合欢原木：

{
    name = "minecraft:stripped_acacia_log",
    count = 32,
    maxCount = 64,
}

物品标签

项目具有的 标签 。

  • tags: { [string] = boolean }：该项目的标签集。这是标签名称到 true 的映射。

虽然标签的表示比单个列表稍微复杂一些，但这使得检查项目是否具有特定标签变得非常容易：

--- Check if the item in the turtle's inventory is a log.
local function is_log(slot)
    local ok, block = turtle.getItemDetail(slot, true)
    return ok and block.tags["minecraft:logs"]
end

例子

一堆去皮的金合欢原木：

{
    name = "minecraft:stripped_acacia_log",
    count = 32,
    tags = {
        ["minecraft:acacia_logs"] = true,
        ["minecraft:logs"] = true,
        ["minecraft:logs_that_burn"] = true,
    }
}

项目组

该项目出现在的广告素材标签上：

  • itemGroups: { { id = string, displayName = string }... }：该项目出现的项目组。每个项目组都存储为一个表，其中包含其 ID 和显示名称。
🛈 版本差异

此信息在 Minecraft 1.19.3 至 1.20.3 上不可用。该字段存在，但在这些版本上为空。

例子

一堆去皮的金合欢原木：

{
    name = "minecraft:stripped_acacia_log",
    count = 32,
    itemGroups = {
        {
            id = "minecraft:building_blocks",
            displayName = "Building Blocks"
        }
    }
}

损坏和耐用性

如果该物品可能被损坏（例如镐），则其损坏和耐用性将可用：

  • damage: number：该物品受到的伤害量。
  • maxDamage: number：该物品受到的最大伤害。
  • durability?: number：如果该物品损坏（即耐久条可见），耐久条上剩余的百分比，介于 0 和 1 之间（含）。
  • unbreakable?: boolean：true，如果该物品牢不可破

例子

未使用过的钻石镐：

{
    name = "minecraft:diamond_pickaxe",
    count = 1,
    damage = 0,
    maxDamage = 1561,
}

一把用了一半的木镐：

{
    name = "minecraft:wooden_pickaxe",
    count = 1,
    damage = 21,
    maxDamage = 59,
    durability = 0.615,
}

结界

该物品具有的魔咒。这包括工具和魔法书籍。

  • enchantments: { table... }：该物品具有的魔咒。每个结界都是一个包含多个属性的表：
    • name: string：此附魔的命名空间 ID，例如minecraft:efficiency。请参阅 Minecraft wiki 以获取原版附魔 ID 列表。
    • displayName: string：该结界的翻译显示名称。
    • level: number：此结界的等级。

例子

效率 V 的金刚石镐：

{
    name = "minecraft:diamond_pickaxe",
    count = 1,
    enchantments = {
        {
            name = "minecraft:efficiency",
            level = 5,
            displayName = "Efficiency V",
        }
    }
}

药水效果

该药水（或浸有药水的物品，例如尖箭）具有的效果：

  • potionEffects: { table... }：该项目具有的效果。每个药水效果都是一个包含几个属性的表：
    • name: string：此效果的命名空间 ID，例如minecraft:regeneration。请参阅 Minecraft wiki 以获取原始效果 ID 列表。
    • displayName: string：该药水效果的翻译显示名称。
    • duration?: number：该效果持续的持续时间（如果不是即时的），以秒为单位。
    • potency?: number：该药水的效力。

例子

基本治疗药水：

{
    name = "minecraft:potion",
    displayName = "Potion of Healing",
    potionEffects = {
        {
            name = "minecraft:instant_health",
            displayName = "Instant Health",
        },
    },
}

升级后的再生药水：

{
    name = "minecraft:potion",
    displayName = "Potion of Regeneration",
    potionEffects = {
        {
            name = "minecraft:regeneration",
            displayName = "Regeneration II",
            duration = 22.5,
            potency = 2,
        },
    },
}

地图颜色

如果指定，则项目的块形式将显示在地图上的颜色。

  • mapColour?: number：块的颜色，以 RGB 十六进制值表示。
  • mapColor?: number：块的颜色，以 RGB 十六进制值表示。

地图颜色仅作为普通数字返回（例如 9923917 表示污垢）。它可以使用 string.format 以十六进制显示，也可以使用 colors.unpackRGB 转换为单独的 RGB 值。

例子

一堆去皮的金合欢原木：

{
    name = "minecraft:stripped_acacia_log",
    count = 32,
    mapColour = 14188339,
    mapColor = 14188339,
}

更改

  • 1.64版本新增功能
  • 在版本1.94.0中进行了更改：添加NBT哈希、物品标签、传说、结界和牢不可破的标志。
  • 版本1.100.9中更改：添加项目组。
  • 在1.117.0版本中进行了更改：添加了地图颜色和药水效果。
