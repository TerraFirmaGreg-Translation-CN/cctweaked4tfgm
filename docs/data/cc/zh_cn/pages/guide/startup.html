在计算机启动时运行程序

当计算机打开时自动开始运行程序通常很有用，例如运行 GPS 主机 时。这可以通过启动文件来完成。

在目录根部创建一个名为 startup.lua 的文件，写入 edit /startup.lua 以及启动时要执行的代码。这里我们用 shell.run 运行 hello 程序。

shell.run("hello")

多个启动文件

启动文件还可用于定义 shell 自动完成、设置或其他设置。在这些情况下，将启动文件拆分为单独的文件可能会很有用。除了 startup.lua 之外，计算机还将运行 startup/ 目录中的任何文件。

让我们创建一个名为 example 的基本程序，它读取设置，并打印其值或切换它：

local cmd = ...
if cmd == "get" then
  print(settings.get("example"))
elseif cmd == "toggle" then
  settings.set("example", not settings.get("example"))
  settings.save()
  print("Toggled our setting")
else
  error("Unknown command", 0)
end

然后我们可以在 startup/example.lua 处创建一个启动文件，该文件添加该程序的完成和设置：

settings.define("example", { type = "boolean", default = true })

local completion = require "cc.shell.completion"
shell.setCompletionFunction("example.lua", completion.build(
  { completion.choice, { "get", "toggle" } }
))

运行此启动文件后，在 shell 中键入 example 应为程序提供自动完成功能。现在，我们可以在 startup/hello.lua 添加另一个启动文件，它（再次）运行 hello：

shell.run("hello")

看到两个启动文件都运行了！
