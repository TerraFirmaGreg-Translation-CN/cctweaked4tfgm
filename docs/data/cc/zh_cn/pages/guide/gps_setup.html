设置 GPS

gps API 允许计算机使用 无线调制解调器找到其当前位置。其工作原理是与已经知道其位置的其他计算机（称为 GPS 主机）进行通信，找到到这些计算机的距离（使用 modem_message），并使用该距离从它们的位置推导出其位置（通过称为 三边测量 的过程。

为了实现这一点，我们需要以特定模式设置 GPS 主机，每个主机在至少一个轴上的位置不同。本指南将引导您完成设置 GPS 主机 星座 并使用它们确定计算机位置的过程。

先决条件

您将需要：

  • 四台计算机。
  • 四个安德调制解调器。可以使用普通的无线调制解调器，但 GPS 星座的范围将受到严重限制。

此外，您还需要另一台计算机和无线调制解调器，以测试 GPS 是否正常工作！

选择一个区域

首先，选择一个地方来构建 GPS 星座。这应该是一个 10x10x10 的立方体，但如果需要，您可以将其缩小。星座越大，在长距离上就越准确，但即使是 5x5x5 的星座也应该服务于数千个区块半径。

必须加载每台计算机才能让其他计算机使用 GPS，因此建议在始终加载的单个块中构建 GPS 星座。您可能想要选择基地中已加载区块的部分或 生成区块 中的区域。如果需要，您可以使用 F3+G 查看块边界。

这是我们将在其中构建星座的示例区域：

构建星座

  1. 将您的第一台计算机放在您所在区域的一个角落，并在上面放置一个调制解调器。
  2. 前往您所在区域的两个相邻角落，放置另外两台计算机，并在每台计算机上放置一个调制解调器。
  3. 将第一台计算机上方的支柱立到立方体的顶部，然后放置最后一台计算机。在计算机上放置调制解调器。

配置星座

现在星座的结构已经构建完成，我们需要配置其中的每个主机。

  1. 按 F3 打开 Minecraft 的调试屏幕。

  2. 回到第一台计算机并查看它。在屏幕右侧大约中间位置，您应该看到一个标记为 Targeted Block 的条目，这些数字对应于您正在查看的块的位置。写下这些数字。

  3. 打开计算机的UI，然后运行edit startup.lua.

  4. 在文件中键入以下代码，将 x、y 和 z 替换为您刚刚记下的坐标。

    shell.run("gps", "host", x, y, z)

  5. 保存文件，然后重新启动计算机（按住Ctrl+R或运行reboot程序）以运行启动程序。

对其他三台计算机重复此过程。

恭喜你，你的星座现已完全建立！您可以通过在附近放置另一台计算机，在其上放置无线调制解调器并运行 gps locate 程序（或调用 gps.locate 函数来测试它。
