打印机

打印机外设允许将文本打印到页面上。然后可以将这些页面一起制作成印刷页面或书籍。

打印机需要墨水（一种有色染料）和纸张才能发挥作用。加载后，可以使用 newPage 开始新页面。然后就可以像普通终端一样使用打印机了； 可以写入文本，光标已移动。打印完所有文本后，应调用 endPage 最终打印页面。

配方

Printer
Printed Pages
Printed Book

用法

  • 打印一个标题为“Hello”的页面，上面有一条小消息。

    local printer = peripheral.find("printer")

-- Start a new page, or print an error.
if not printer.newPage() then
 error("Cannot start a new page. Do you have ink and paper?")
end

-- Write to the page
printer.setPageTitle("Hello")
printer.write("This is my first page")
printer.setCursorPos(1, 3)
printer.write("This is two lines below.")

-- And finally print the page!
if not printer.endPage() then
 error("Cannot end the page. Is there enough space?")
end

write(text)Source

将文本写入当前页面。

参数

  1. text string 要写入页面的值。

抛出

  • 如果有任何值无法转换为字符串，或者没有启动页面。

getCursorPos()Source

返回光标在页面上的当前位置。

返回

  1. number 光标的 X 位置。
  2. number 光标的 Y 位置。

抛出

  • 如果未打印页面。

setCursorPos(x, y)Source

设置页面上光标的位置。

参数

  1. x number 设置光标的 X 坐标。
  2. y number 设置光标的 Y 坐标。

抛出

  • 如果未打印页面。

getPageSize()Source

返回当前页面的大小。

返回

  1. number 页面的宽度。
  2. number 页面的高度。

抛出

  • 如果未打印页面。

newPage()Source

开始打印新页面。

返回

  1. boolean 是否可以开始新页面。
endPage()Source

完成当前页面的打印并将其输出到纸盘。

返回

  1. boolean 页面是否可以成功完成。

抛出

  • 如果未打印页面。

setPageTitle([title])Source

设置当前页面的标题。

参数

  1. 标题? string 要为页面设置的标题。

抛出

  • 如果未打印页面。

getInkLevel()Source

返回打印机中剩余的墨水量。

返回

  1. number 可用于打印的墨水量。
getPaperLevel()Source

返回打印机中剩余的纸张量。

返回

  1. number 可用于打印的纸张数量。
