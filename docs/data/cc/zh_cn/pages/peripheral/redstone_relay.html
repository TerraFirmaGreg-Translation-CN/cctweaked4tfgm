红石继电器

红石继电器是一种允许读取和输出红石信号的外设。虽然这本身并不是很有用（因为计算机具有相同的功能内置），但它可以与有线调制解调器一起使用，与来自同一台计算机的多个红石信号进行交互。

该外设提供与计算机内置 redstone API 基本相同的方法，允许在块的所有六个侧面（“顶部”、“底部”、“左”、“右”、“前”和“后”）设置信号。

食谱

Redstone Relay

用法

  • 每 0.5 秒切换计算机上方的红石信号。

    local relay = peripheral.find("redstone_relay")
while true do
 relay.setOutput("top", not relay.getOutput("top"))
 sleep(0.5)
end

setOutput(side, on)Source

打开或关闭特定面的红石信号。

参数

  1. side string 要设置的面。
  2. on boolean 红石信号应开启还是关闭。开启时，会发出强度为 15 的信号。
getOutput(side)Source

获取指定面的当前红石输出。

参数

  1. side string 要获取的面。

返回值

  1. boolean 红石输出是开启还是关闭。

另见

  • setOutput
getInput(side)Source

获取指定面的当前红石输入。

参数

  1. side string 要获取的面。

返回值

  1. boolean 红石输入是开启还是关闭。
setAnalogOutput(side, value)Source

设置指定面的红石信号强度。

参数

  1. side string 要设置的面。
  2. value number 0 到 15 之间的信号强度。

抛出

  • 如果 value 不在 0 到 15 之间。

testBundledInput(side, mask)Source

判断给定面上一组特定颜色组合是否开启。

参数

  1. side string 要测试的面。
  2. mask number 要测试的掩码。

返回值

  1. boolean 这些颜色是否开启。

用法

  • 检查此方块上方的 colors.white 和 colors.black 是否开启。

    print(redstone.testBundledInput("top", colors.combine(colors.white, colors.black)))

另见
