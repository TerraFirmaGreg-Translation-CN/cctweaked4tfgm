调制解调器

调制解调器允许你在计算机之间远距离发送消息。

提示

调制解调器提供了一组相当基本的方法，这使得它们非常灵活，但通常很难使用。 rednet API 构建在调制解调器之上，并提供更加用户友好的界面。

发送和接收消息

调制解调器在一系列通道上运行，有点像收音机上的频率。任何调制解调器都可以在特定通道上发送消息，但只有打开通道并“监听”的调制解调器才能接收消息。

通道表示为 0 到 65535 之间的整数（含 0 和 65535）。这些通道没有任何定义的含义，尽管某些 API 或程序会为其指定含义。例如，gps 模块在通道 65534 (gps.CHANNEL_GPS) 上发送其所有消息，而 rednet 使用等于计算机 ID 的通道。

  • 发送消息是通过 transmit 消息完成的。
  • 接收消息是通过监听 modem_message 事件来完成的。

调制解调器的类型

CC：Tweaked 配备了三种调制解调器，具有不同的功能。

  • 无线调制解调器：无线调制解调器可以向任何其他无线调制解调器发送消息。它们可以放置在计算机旁边，或者作为袖珍计算机或乌龟升级版配备。

    无线调制解调器的范围有限，只能向 64 个块内的调制解调器发送消息。一旦调制解调器高于 y=96，此范围就会线性增加，在世界高度处最大为 384。

  • Ender 调制解调器： 这些是普通无线调制解调器的升级版本。它们没有距离限制，可以在维度之间发送消息。

  • 有线调制解调器：这些调制解调器将消息发送到连接到同一网络的其他任何有线调制解调器（使用网络线缆）。它们还可用于将其他外设连接到计算机。

用法

  • 在通道 15 上包装调制解调器和消息，请求通道 43 上的响应。然后等待消息到达通道 43 并打印它。

    local modem = peripheral.find("modem") or error("No modem attached", 0)
modem.open(43) -- Open 43 so we can receive replies

-- Send our message
modem.transmit(15, 43, "Hello, world!")

-- And wait for a reply
local event, side, channel, replyChannel, message, distance
repeat
 event, side, channel, replyChannel, message, distance = os.pullEvent("modem_message")
until channel == 43

print("Received a reply: " .. tostring(message))

open(channel)Source

在调制解调器上打开一个通道。必须打开通道才能接收消息。调制解调器一次最多可以打开 128 个通道。

参数

  1. 通道 number 要打开的通道。该值必须是 0 到 65535 之间的数字。

抛出

  • 如果频道超出范围。

  • 如果开放通道过多。

isOpen(channel)Source

检查通道是否打开。

参数

  1. 通道 number 要检查的通道。

返回

  1. boolean 通道是否打开。

抛出

  • 如果频道超出范围。

close(channel)Source

关闭一个打开的通道，意味着它将不再接收消息。

参数

  1. 通道 number 要关闭的通道。

抛出

  • 如果频道超出范围。

closeAll()Source

关闭所有打开的通道。

transmit(channel, replyChannel, payload)Source

在特定通道上发送调制解调器消息。侦听通道的调制解调器将在相邻计算机上对 modem_message 事件进行排队。

🛈 注意

无需打开通道即可发送消息。

参数

  1. 通道 number 发送消息的通道。
  2. replyChannel number 应发送响应此消息的通道。这可以与 channel 相同或完全不同。发送计算机上的通道必须已打开才能接收回复。
  3. payload any 要发送的对象。这可以是任何原始类型（布尔值、数字、字符串）以及表。其他类型（如函数）以及元表将不会被传输。

抛出

  • 如果频道超出范围。

用法

  • 在通道 15 上封装调制解调器和一条消息，请求在通道 43 上做出响应。

    local modem = peripheral.find("modem") or error("No modem attached", 0)
modem.transmit(15, 43, "Hello, world!")
isWireless()Source

确定这是有线调制解调器还是无线调制解调器。

某些方法（即处理有线网络和远程外设的方法）仅适用于有线调制解调器。

返回

  1. booleantrue（如果这是无线调制解调器）。
getNamesRemote()Source

列出有线网络上的所有远程外设。

如果此计算机连接到网络，则它将不会包含在此列表中。

🛈 注意

此功能仅出现在有线调制解调器上。在调用之前检查 isWireless 返回 false。

返回

  1. { string... } 网络上的远程外设名称。
isPresentRemote(name)Source

确定外设在此有线网络上是否可用。

🛈 注意

此功能仅出现在有线调制解调器上。在调用之前检查 isWireless 返回 false。

参数

  1. 名称 string 外设的名称。

返回

  1. boolean 布尔值 是否存在具有给定名称的外设。

返回当前计算机的网络名称（如果调制解调器已打开）。网络上的其他计算机可以使用它来将此计算机包装为外设。

🛈 注意

此功能仅出现在有线调制解调器上。在调用之前检查 isWireless 返回 false。

返回
