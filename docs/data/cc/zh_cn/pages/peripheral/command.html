命令

该外设允许你与命令方块交互。

如果配置中的 enable_command_block 选项为 true，则命令块仅包装为外设。

这个 API 并不等同于 commands API——后者只在命令计算机上提供。

getCommand()获取此命令块将运行的命令。
setCommand(command)设置命令块的命令。
runCommand()执行一次命令块。
getCommand()Source

获取此命令块将运行的命令。

返回

  1. string 当前命令。
setCommand(command)Source

设置命令块的命令。

参数

  1. 命令 string 新命令。
runCommand()Source

执行命令块一次。

返回

  1. boolean 如果命令成功完成。
  2. string | nil 失败消息。
