驾驶

磁盘驱动器是一种外设，允许您读取和写入软盘和其他“可安装介质”（例如计算机或海龟）。它们还允许您播放唱片。

当磁盘驱动器附加某些安装（例如软盘或计算机）时，它会将名为 disk、disk2 等的文件夹附加到计算机的根目录。该文件夹可用于与该磁盘上的文件进行交互。

当插入磁盘时，会触发 disk 事件，同时侧外设打开。同样，当磁盘分离时，会触发 disk_eject 事件。

isDiskPresent()Source

返回磁盘当前是否已插入驱动器。

返回

  1. boolean 驱动器中当前是否插入了磁盘。
getDiskLabel()Source

返回驱动器中磁盘的标签（如果可用）。

返回

  1. string | nil 磁盘的标签，如果未插入磁盘或磁盘没有标签，则为 nil。
setDiskLabel([label])Source

设置或清除磁盘的标签。

如果没有标签或传递nil，则标签将被清除。

如果插入的磁盘的标签无法更改（例如，一条记录），则会抛出错误。

参数

  1. label? string 磁盘的新标签，或 nil 进行清除。

抛出

  • 如果磁盘的标签无法更改。
