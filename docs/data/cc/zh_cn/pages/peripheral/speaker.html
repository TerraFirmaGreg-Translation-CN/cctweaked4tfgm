扬声器

扬声器外设允许你的计算机播放音符和其他声音。

扬声器可以播放三种声音，按复杂程度递增：

  • playNote 允许您播放音符块音符。
  • playSound 播放任何 Minecraft 声音，例如方块声音或生物噪音。
  • playAudio可以播放任意音频。

playNote(instrument [, volume [, pitch]])Source

通过扬声器播放音符块音符。

这需要要播放的音符的名称，以及播放音符的可选音量和音高。

音​​高参数使用半音作为单位。这直接映射到音符块上的点击次数。作为参考，0、12 和 24 映射到 F#，6 和 18 映射到 C。

单个刻度最多可以演奏 8 个音符。如果达到此限制，此函数将返回 false。

有效乐器

扬声器支持 所有 Minecraft 的 noteblock 乐器。它们是：

"harp"、"basedrum"、"snare"、"hat"、"bass"、"flute"、"bell"、"guitar"、"chime"、"xylophone"、"iron_xylophone"、"cow_bell"、"didgeridoo"、"bit"、 "banjo" 和 "pling".

参数

  1. 乐器 string 用于演奏此音符的乐器。
  2. 音量? number 演奏音符的音量，从 0.0 到 3.0。默认为 1.0。
  3. 音高? number 演奏音符的音高（以半音为单位），从 0 到 24。默认为 12。

返回

  1. boolean 达到限制后是否可以播放音符。

抛出

  • 如果仪器不存在。

playSound(name [, volume [, pitch]])Source

通过扬声器播放 Minecraft 声音。

它接受原版 Minecraft或模组声音的名称（例如 "minecraft:block.note_block.harp"），以及可选音量和音调。

同一时间只能播放一个声音。如果本刻已经开始了另一个声音，此函数会返回 false；或者仍有 音频在播放。

参数

  1. 名称 string 要播放的声音的名称。
  2. 音量? number 播放声音的音量，从 0.0 到 3.0。默认为 1.0。
  3. 音高? number 播放声音的速度，从 0.5 到 2.0。默认为 1.0。

返回值

  1. boolean是否可以播放声音。

抛出

  • 如果声音名称无效。

用法

  • 用扬声器发出苦力怕的嘶嘶声。

    local speaker = peripheral.find("speaker")
speaker.playSound("entity.creeper.primed")
playAudio(audio [, volume])Source

尝试将一些音频数据传输到扬声器。

它接受幅度介于 -128 和 127 之间的音频样本列表。这些样本存储在内部缓冲区中并以 48kHz 播放。如果该缓冲区已满，该函数将返回 false。程序应在尝试再次播放音频之前等待 speaker_audio_empty 事件。

扬声器一次仅缓冲对 playAudio 的单个调用。这意味着如果您尝试播放少量样本，就会出现很多卡顿现象。您应该尝试在一次通话中播放尽可能多的样本（最多 128×1024），因为这可以减少音频卡顿或停止的可能性，特别是当服务器或计算机滞后时。

虽然扬声器接受 8 位 PCM 音频，但音频流在播放之前会重新编码。这意味着提供的样本可能无法准确播放。

使用扬声器播放音频提供了有关使用扬声器的更完整的指南。

参数

  1. 音频 { number... } 幅度列表。
  2. 音量? number 播放此音频的音量。如果未指定，则默认为 playAudio 之前指定的音量。

返回

  1. boolean 是否有空间接受此音频数据。

抛出

  • 如果音频数据格式错误。

用法

  • 读取音频文件，使用 cc.audio.dfpwm 进行解码，然后使用扬声器播放。

    local dfpwm = require("cc.audio.dfpwm")
local speaker = peripheral.find("speaker")

local decoder = dfpwm.make_decoder()
for chunk in io.lines("data/example.dfpwm", 16 * 1024) do
   local buffer = decoder(chunk)

   while not speaker.playAudio(buffer) do
       os.pullEvent("speaker_audio_empty")
   end
end

stop()Source

停止此扬声器播放的所有音频。

这将清除 playAudio 已排队的所有音频，并停止 playSound.
