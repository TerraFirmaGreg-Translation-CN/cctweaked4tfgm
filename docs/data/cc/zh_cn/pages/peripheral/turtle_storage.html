海龟存储

turtle_storage 允许你为海龟装备潜影盒或其他存储物品并访问其内容。

这与 inventory 基本上具有相同的方法和形状，除了 pullItems 和 pushItems 与海龟的库存之间转移，而不是采用库存名称。

🛈 信息

此升级和外设目前处于实验阶段。它只能通过 computercraft/turtle_storage 数据包启用，并且方法可能会发生变化。

更改

  • 版本 1.121.0 中的新增功能
size()获取此库存的大小。
list()列出此库存中的所有物品。
getItemDetail(slot)获取有关某个项目的详细信息。
pushItems(fromSlot [, limit [, toSlot]])将物品从该库存推送给乌龟。
pullItems([fromSlot [, limit [, toSlot]]])将乌龟身上的物品放入此库存中。
size()Source

获取此库存的大小。

返回

  1. number 此库存中的槽数。
list()Source

列出此库存中的所有物品。这将返回一个表，每个槽都有一个条目。

这将返回与 inventory.list相同格式的数据。

返回

  1. { table |无... } 有关此库存中所有商品的基本信息。

另请参阅

  • Item details
  • inventory.list
getItemDetail(slot)Source

获取有关某个项目的 详细信息。

参数

  1. slot number 要获取相关信息的插槽。

返回

  1. table | nil 有关此插槽中项目的信息，如果为空，则为 nil。

抛出

  • 如果槽位超出范围。

另请参阅

  • Item details
  • inventory.getItemDetail
pushItems(fromSlot [, limit [, toSlot]])Source

将此物品栏中的物品推入乌龟。

参数

  1. fromSlot number 当前库存中要将物品移动到的位置。
  2. limit? number 要移动的最大项目数。默认为当前堆栈限制。
  3. toSlot? number 海龟中要移动到的位置。如果没有给出，该项目将被插入到任何插槽中。

返回

  1. number 传输的项目数。

抛出

  • 如果源或目标插槽超出范围。

pullItems([fromSlot [, limit [, toSlot]]])Source

将海龟中的物品拉入此库存。

参数

  1. fromSlot? number 海龟库存中要从中移动物品的插槽，默认为当前选定的插槽。
  2. limit? number 要移动的最大项目数。默认为当前堆栈限制。
  3. toSlot? number 当前库存中要移动到的位置。如果没有给出，该项目将被插入到任何插槽中。

返回

  1. number 传输的项目数。

抛出

  • 如果源或目标插槽超出范围。
