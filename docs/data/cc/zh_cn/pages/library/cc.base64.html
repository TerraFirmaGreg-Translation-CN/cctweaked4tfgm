cc.base64

cc.base64 模块提供了在二进制数据与 Base64 之间相互转换的函数。

用法

  • 对 Base64 字符串进行编码和解码。

    local base64 = require "cc.base64"
print(base64.encode("Hello, world"))
print(base64.decode("SGVsbG8sIHdvcmxk"))

encode(str [, alt_chars="+/"])Source

将二进制字符串编码为 Base64。

参数

  1. str string 要编码的二进制数据。
  2. alt_chars? string = "+/" 长度为 2 的字符串，用于编码第 62 位和第 63 位。

返回

  1. string Base64 编码数据。

用法

  • 将字符串转换为 Base64

    local base64 = require "cc.base64"
print(base64.encode("Hello, world!"))

  • 将字符串转换为base64url。这是 Base64 的另一种形式，其中字符串使用 "-_" 而不是 "+/" 进行编码。这使得字符串可以更容易地在 URL 中使用，尽管填充 = 仍然需要使用 textutils.urlEncode.

    local base64 = require "cc.base64"
print(base64.encode("Test: \255\230", "-_"))

decode(str [, alt_chars="+/"])Source

将 Base64 编码的字符串解码回其原始数据。

此函数要求数据是有效的 Base64 且带有尾部填充字节。

参数

  1. str string 要解码的 Base64 编码数据。
  2. alt_chars? string = "+/" 长度为 2 的字符串，用于编码第 62 位和第 63 位。

返回

  1. string 解码数据。

或

  1. nil 如果数据不是有效的 Base64，或者缺少尾部填充。
  2. string 数据解码失败的原因。

用法

  • 从 Base64 解码字符串

    local base64 = require "cc.base64"
print(base64.decode("SGVsbG8sIHdvcmxk"))

  • 解码 base64url 编码的数据。

    local base64 = require "cc.base64"
print(base64.decode("VGVzdDog_-Y=", "-_"))
