choice(text, choices [, add_space])Source

由一个或多个字符串的选择完成。

参数

  1. text string 要完成的输入字符串。
  2. choices { string... } 要完成的选项列表。
  3. add_space? boolean 是否在完成的项目后添加空格。

返回

  1. { string... } 匹配字符串的后缀列表。

用法

  • 呼叫_G.read，补全各种动物的名字。

    local completion = require "cc.completion"
local animals = { "dog", "cat", "lion", "unicorn" }
read(nil, nil, function(text) return completion.choice(text, animals) end)
