抄送要求

内置 require 函数和 package 库的纯 Lua 实现。

通常您不需要使用此模块 - 它被注入到每个程序的环境中。但是，在构建自定义 shell 或自己运行程序时，它可能很有用。

用法

  • 构建包和 require 函数，并将它们插入自定义环境中。

    local r = require "cc.require"
local env = setmetatable({}, { __index = _ENV })
env.require, env.package = r.make(env, "/")

-- Now we have our own require function, separate to the original.
local r2 = env.require "cc.require"
print(r, r2)

make(env, dir)Source

构建 Lua 的 package 库的实现，以及一个 require 函数来加载其中的模块。

参数

  1. env table 将包加载到的环境。
  2. dir string 加载相关包的目录。

返回

  1. function 新的 require 函数。
  2. table 新的 package 库。
