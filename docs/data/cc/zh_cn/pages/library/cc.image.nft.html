cc.image.nft

读取并绘制 nft（“Nitrogen Fingers Text”）图像。

nft（“氮指文本”）是一种用于绘制基本图像的文件格式。与 paintutils.parseImage 使用的图像不同，nft 支持彩色文本以及简单的彩色像素。

用法

  • 从 example.nft 加载图像并绘制它。

    local nft = require "cc.image.nft"
local image = assert(nft.load("data/example.nft"))
nft.draw(image, term.getCursorPos())

parse(image)Source

从字符串中解析nft图像。

参数

  1. 图像 string图像内容。

返回

  1. 表 解析后的图像。
load(path)Source

从文件加载 nft 图像。

参数

  1. path string 要加载的文件。

返回

  1. table 解析后的图像。

或

  1. nil 如果文件不存在或无法加载。
  2. string 一条错误消息，解释无法加载文件的原因。
draw(image, xPos, yPos [, target])Source

在屏幕上绘制nft图像。

参数

  1. 图像 table 从 load 或 parse 返回的图像。
  2. xPos number 开始绘制的 x 坐标。
  3. yPos number 开始绘制的 y 坐标。
  4. target? term.Redirect 要绘制的终端重定向。默认为当前终端。
