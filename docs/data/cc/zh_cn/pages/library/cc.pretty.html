cc.漂亮

一个用于以美观方式渲染数据结构的格式化打印器。

为了使用 cc.pretty 显示某些内容，您需要构建一系列 文档 。它们的行为有点像字符串；您可以将它们连接在一起，然后将它们打印到屏幕上。

但是，文档还允许您控制它们的打印方式。有多个函数（例如 nest 和 group）允许您控制文档的“布局”。当您显示文档时，将使用“最佳”（最紧凑）布局。

该模块的结构基于A Prettier Printer。

用法

  • 将表格打印到终端

    local pretty = require "cc.pretty"
pretty.pretty_print({ 1, 2, 3 })

  • 构建自定义文档并显示它

    local pretty = require "cc.pretty"
pretty.print(pretty.group(pretty.text("hello") .. pretty.space_line .. pretty.text("world")))

emptySource

一个空文档。

spaceSource

其中有一个空格的文档。

lineSource

换行。当用 group 折叠时，它将被替换为 empty.

space_lineSource

换行。当用 group 折叠时，它将被替换为 space.

text(text [, colour])Source

从字符串创建新文档。

如果字符串包含多行，group会将字符串平铺为单行，每行之间有空格。

参数

  1. text string 用于构造新文档的字符串。
  2. color? number 该文本应打印的颜色。如果没有给出，我们默认使用当前颜色。

返回

  1. Doc 包含所提供文本的文档。

用法

  • 写一些蓝色文本。

    local pretty = require "cc.pretty"
pretty.print(pretty.text("Hello!", colours.blue))
concat(...)Source

将多个文档连接在一起。这与字符串连接的行为非常相似。

参数

  1. ... Doc | string 要连接的文档。

返回

  1. Doc 串联文档。

用法

  • local pretty = require "cc.pretty"
local doc1, doc2 = pretty.text("doc1"), pretty.text("doc2")
print(pretty.concat(doc1, " - ", doc2))
print(doc1 .. " - " .. doc2) -- Also supports ..
nest(depth, doc)Source

使用给定的空格数缩进给定文档的后面几行。

例如，将文档

foo
bar

嵌套两个空格将产生

foo
  bar

参数

  1. 深度 number 文档应缩进的空格数。
  2. doc Doc 要缩进的文档。

返回

  1. Doc 嵌套文档。

用法

  • local pretty = require "cc.pretty"
print(pretty.nest(2, pretty.text("foo\nbar")))
group(doc)Source

构建一个文档，如果有足够的空间，则该文档显示在单行上；如果没有足够的空间，则按正常方式显示。

参数

  1. doc Doc 要分组的文档。

返回

  1. Doc 分组文档。

用法

  • 使用组来显示在一行或多行上显示的内容。

    local pretty = require "cc.pretty"
local doc = pretty.group("Hello" .. pretty.space_line .. "World")
print(pretty.render(doc, 5)) -- On multiple lines
print(pretty.render(doc, 20)) -- Collapsed onto one.

在终端上显示文档。

参数

  1. doc Doc 要渲染的文档
  2. ribbon_frac? number = 0.6 我们应该写入的宽度的最大分数。
print(doc [, ribbon_frac=0.6])Source

在终端上显示带有换行符的文档。

参数

  1. doc Doc 要渲染的文档。
  2. ribbon_frac? number = 0.6 我们应该写入的宽度的最大分数。
render(doc [, width [, ribbon_frac=0.6]])Source

渲染文档，将其转换为字符串。

参数

  1. doc Doc 要渲染的文档。
  2. 宽度? number 该文档的最大宽度。请注意，长字符串不会被换行以适应此宽度 - 它仅用于查找最佳布局。
  3. ribbon_frac? number = 0.6 我们应该写入的宽度的最大分数。

返回

  1. string 以字符串形式呈现的文档。
pretty(obj [, options])Source

漂亮打印任意对象，将其转换为文档。

然后可以使用 write 或 print 进行渲染。

参数

  1. obj 要漂亮打印的对象。
  2. options? { function_args = boolean, function_source = boolean }

    控制各种属性的显示方式。

    • function_args：显示函数的参数（如果已知）（默认为 false）。
    • function_source：显示定义函数的位置，而不是 function: xxxxxxxx（默认为 false）。

返回

  1. Doc 格式化为文档的对象。

用法

  • 在屏幕上显示表格

    local pretty = require "cc.pretty"
pretty.print(pretty.pretty({ 1, 2, 3 }))

另请参见

  • pretty_print 用于美化和打印对象的简写。

类型

文档

包含格式化文本的文档，具有多种可能的布局。

文档有效地表示了替代布局中的一系列字符串，我们将尝试以必要的最紧凑的形式进行打印。
