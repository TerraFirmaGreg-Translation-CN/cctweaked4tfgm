wrap(text [, width])Source

换行文本块，使每行适合给定宽度。

如果您想在将文本显示到 monitor 或 printer 之前换行文本而不使用 print.

，这可能很有用

参数

  1. text string 要换行的字符串。
  2. width? number 要约束的宽度，默认为终端的宽度。

返回

  1. { string... } 将输入字符串包装为行列表。

用法

  • 包装一个字符串并将其写入终端。

    term.clear()
local lines = require "cc.strings".wrap("This is a long piece of text", 10)
for i = 1, #lines do
  term.setCursorPos(1, i)
  term.write(lines[i])
end
ensure_width(line [, width])Source

使输入字符串具有固定宽度。这会截断它，或者用空格填充它。

参数

  1. line string 要规范化的字符串。
  2. width? number 要约束的宽度，默认为终端的宽度。

返回

  1. string 具有特定宽度的字符串。

用法

  • require "cc.strings".ensure_width("a short string", 20)
  • require "cc.strings".ensure_width("a rather long string which is truncated", 20)
split(str, deliminator [, plain=false [, limit]])Source

按分隔符把字符串拆分为多段。

例如，拆分字符串 "a b c" 时使用分隔符 " "，会得到一个包含三个字符串的表："a"、"b" 和 "c"。

默认情况下，分隔符按 Lua 模式解释。传入 true 给 plain 参数会让分隔符按字面字符串处理。

参数

  1. str string 要分割的字符串。
  2. 分隔符 string 分割此字符串的模式。
  3. plain? boolean = false 将分隔符视为普通字符串，而不是模式。
  4. limit? number 返回列表中元素的最大数量。

返回值

  1. { string... } 分割字符串列表。

用法

  • 将字符串拆分为单词。

    require "cc.strings".split("This is a sentence.", "%s+")

  • 用“-”将字符串分割成最多3个元素。

    require "cc.strings".split("a-separated-string-of-sorts", "-", true, 3)

参见

  • table.concat 将字符串连接在一起。
