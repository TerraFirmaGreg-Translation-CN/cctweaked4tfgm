cc.shell.completion

一组用于处理命令行补全的辅助方法。

大多数程序可以使用 build 辅助方法完成，而不是手动打开参数索引。

请注意，此模块中的辅助函数不接受参数索引，因此不能直接与 shell.setCompletionFunction 一起使用。相反，使用 build 或您自己的自定义函数来包装它们。

用法

  • 为 example.lua 注册一个完成处理程序，它会提示选择选项，然后是一个目录，然后是多个文件。

    local completion = require "cc.shell.completion"
local complete = completion.build(
  { completion.choice, { "get", "put" } },
  completion.dir,
  { completion.file, many = true }
)
shell.setCompletionFunction("example.lua", complete)
read(nil, nil, shell.complete, "example ")

另请参阅

  • cc.completion 对于更通用的助手，适合与 _G.read 一起使用。
  • shell.setCompletionFunction

file(shell, text)Source

完成相对于当前工作目录的文件名。

参数

  1. shell table 我们正在完成的 shell。
  2. 文本 string 当前要完成的文本。

返回

  1. { string... } 匹配文件的后缀列表。

完成相对于当前工作目录的目录名称。

参数

  1. shell table 我们正在完成的 shell。
  2. 文本 string 当前要完成的文本。

返回

  1. { string... } 匹配目录的后缀列表。
dirOrFile(shell, text, previous [, add_space])Source

完成相对于当前工作目录的文件或目录的名称。

参数

  1. shell table 我们正在完成的 shell。
  2. 文本 string 当前要完成的文本。
  3. 前一 { string... } 在此之前的 shell 参数。
  4. add_space? boolean 是否在完成的项目后添加空格。

返回

  1. { string... } 匹配文件和目录的后缀列表。

程序的完整参数。

  1. shell table 我们正在完成的 shell。

build(...)Source

用于构建 shell 完成参数的辅助函数。

它接受一系列单参数完成函数，并将它们组合成一个适合与 shell.setCompletionFunction.

参数

  1. ... 零 | table | function

    build 的每个参数代表您希望完成的程序的一个参数。每个参数可以是以下三种类型之一：

    • nil：这个论证不会完成。

    • 函数：该参数将用给定的函数完成。它是使用 shell 对象、要完成的字符串以及此字符串之前的参数来调用的。

    • 表：这充当功能案例的更强大版本。该表必须有一个函数作为第一项 - 这将使用上面的 shell、字符串和前面的参数来调用，但后面还可以跟上表中的任何其他项。这提供了一个更方便的接口来将选项传递给完成函数。

      如果此表是最后一个参数，它还可以将 many 键设置为 true，这表明应使用此函数来完成任何剩余的参数。
