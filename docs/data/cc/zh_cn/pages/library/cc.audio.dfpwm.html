cc.音频.dfpwm

在 DFPWM 音频数据流和振幅列表之间转换。

DFPWM（动态滤波器脉冲宽度调制）是 GreaseMonkey 设计的音频编解码器。与原始 PCM 数据相比，它是一种相对紧凑的格式，每个样本仅使用 1 位，但足够简单，可以实时编码和解码。

通常，DFPWM 音频从 文件系统 或 Web 请求 作为字符串读取，并转换为适合 speaker.playAudio 的格式。

编码和解码文件

该模块公开了两个关键函数，make_decoder和make_encoder，它们构造了一个新的解码器或编码器。返回的编码器/解码器本身就是一个函数，它在两种数据之间进行转换。

这些编码器和解码器具有大量隐藏状态，因此您应该小心地对特定音频流使用相同的编码器或解码器。通常，您需要为您读取的每个音频流创建一个解码器，并为您编写的每个音频流创建一个编码器。

将音频转换为 DFPWM

DFPWM 不是一种流行的文件格式，因此标准音频处理工具可能没有导出到它的选项。相反，您可以使用 music.madefor.cc、LionRay Wav Converter Java 应用程序或 FFmpeg 5.1 或更高版本在线转换音频文件。

用法

  • 分块读取“data/example.dfpwm”，对其进行解码，然后将音频速度加倍。然后，生成的音频被重新编码并保存到“speedy.dfpwm”。然后可以使用 speaker 程序播放经过处理的音频。

    local dfpwm = require("cc.audio.dfpwm")

local encoder = dfpwm.make_encoder()
local decoder = dfpwm.make_decoder()

local out = fs.open("speedy.dfpwm", "wb")
for input in io.lines("data/example.dfpwm", 16 * 1024 * 2) do
  local decoded = decoder(input)
  local output = {}

  -- Read two samples at once and take the average.
  for i = 1, #decoded, 2 do
    local value_1, value_2 = decoded[i], decoded[i + 1]
    output[(i + 1) / 2] = (value_1 + value_2) / 2
  end

  out.write(encoder(output))

  sleep(0) -- This program takes a while to run, so we need to make sure we yield.
end
out.close()

make_encoder()Source

创建一个新的编码器，用于将 PCM 音频数据转换为 DFPWM。

返回的编码器本身就是一个函数。此函数接受 -128 到 127 之间的幅度数据表，并返回编码的 DFPWM 数据。

⚠ 重用编码器

编码器有很多内部状态来跟踪当前流的状态。如果您对多个流重复使用一个编码器，或者对同一流使用不同的编码器，则生成的音频听起来可能不正确。

返回

  1. function(pcm: { number... }):string The encoder function

make_decoder()Source

创建一个新的解码器，用于将 DFPWM 转换为 PCM 音频数据。

返回的解码器本身就是一个函数。此函数接受一个字符串并返回一个幅度表，每个值介于 -128 和 127 之间。

⚠ 重用解码器

解码器有很多内部状态来跟踪当前流的状态。如果您对多个流重复使用一个解码器，或者对同一流使用不同的解码器，则生成的音频听起来可能不正确。

返回

  1. function(dfpwm: string):{ number... } The encoder function

用法

  • 以 16KiB 的块读取“data/example.dfpwm”（扬声器最多可接受 128×1024 个样本），对其进行解码，然后通过扬声器播放它们。

    local dfpwm = require "cc.audio.dfpwm"
local speaker = peripheral.find("speaker")

local decoder = dfpwm.make_decoder()
for input in io.lines("data/example.dfpwm", 16 * 1024) do
  local decoded = decoder(input)
  while not speaker.playAudio(decoded) do
    os.pullEvent("speaker_audio_empty")
  end
end
