websocket_失败

websocket_failure 事件在 WebSocket 连接请求失败时触发。

该事件通常在http.websocket内部处理，但在使用http.websocketAsync时仍然可以看到。

返回值

  1. string：事件名称。
  2. string：请求的站点的 URL。
  3. string：描述失败的错误。

例子

打印无法联系网站的错误：

local myURL = "wss://example.tweaked.cc/not-a-websocket"
http.websocketAsync(myURL)
local event, url, err
repeat
    event, url, err = os.pullEvent("websocket_failure")
until url == myURL
print("The URL " .. url .. " could not be reached: " .. err)
