http_成功

当 HTTP 请求成功返回时，会触发 http_success 事件。

该事件通常在 http.get 和 http.post 内部处理，但在使用 http.request 时仍然可以看到。

返回值

  1. string：事件名称。
  2. string：请求的站点的 URL。
  3. http.Response：成功的 HTTP 响应。

例子

打印网站的内容（如果请求失败，则可能会失败）：

local myURL = "https://tweaked.cc/"
http.request(myURL)
local event, url, handle
repeat
    event, url, handle = os.pullEvent("http_success")
until url == myURL
print("Contents of " .. url .. ":")
print(handle.readAll())
handle.close()
