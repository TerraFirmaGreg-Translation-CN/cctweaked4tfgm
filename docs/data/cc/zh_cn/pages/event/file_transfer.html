文件传输

当用户在打开的计算机上拖放文件时，file_transfer 事件会被加入队列。

此事件只包含一个类型为 TransferredFiles 的参数，可通过它获取待传输的文件。返回的每个文件都是一个二进制文件句柄，并额外提供 getName 方法。

返回值

  1. string：事件名称
  2. TransferredFiles：已传输文件的列表。

例子

等待用户将文件拖放到计算机上，然后打印文件列表和每个文件的大小。

local _, files = os.pullEvent("file_transfer")
for _, file in ipairs(files.getFiles()) do
  -- Seek to the end of the file to get its size, then go back to the beginning.
  local size = file.seek("end")
  file.seek("set", 0)

  print(file.getName() .. " " .. size)
end

例子

将每个传输的文件保存到计算机的存储器中。

local _, files = os.pullEvent("file_transfer")
for _, file in ipairs(files.getFiles()) do
  local handle = fs.open(file.getName(), "wb")
  handle.write(file.readAll())

  handle.close()
  file.close()
end

更改

  • 1.101.0版本中的新增功能

类型

已传输文件

已传输到此计算机的文件列表。

TransferredFiles.getFiles()Source

正在传输到此计算机的所有文件。

返回

  1. { file_transfer.TransferredFile... } 文件列表。

已传输文件

已传输到此计算机的二进制文件句柄。

它继承了二进制文件句柄的所有方法，这意味着您可以使用标准读取函数来访问文件的内容。

另请参阅

  • fs.ReadHandle
TransferredFile.getName()Source

获取正在传输的文件的名称。

返回

  1. string 文件名。
