按键向上

每当释放按键（或在按住按键时关闭终端）时触发。

此事件返回一个数字“键代码”（例如，F1 是 290）。该值可能因版本而异，因此建议使用 keys API 中的常量，而不是硬编码数值。

返回值

  1. string：事件名称。
  2. number：按下的键的数字键值。

例子

每当触发 key_up 事件时，打印键盘上释放的每个键。

while true do
  local event, key = os.pullEvent("key_up")
  local name = keys.getName(key) or "unknown key"
  print(name .. " was released.")
end
