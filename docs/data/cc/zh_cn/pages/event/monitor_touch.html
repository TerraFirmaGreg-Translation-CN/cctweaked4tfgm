监听触摸

monitor_touch 事件会在相邻或联网的 高级显示器 被右键点击时触发。

返回值

  1. string：事件名称。
  2. string：所触摸的显示器的侧面或网络 ID。
  3. number：触摸的 X 坐标，以字符为单位。
  4. number：触摸的 Y 坐标，以字符为单位。

例子

当触摸监视器时打印一条消息：

while true do
  local event, side, x, y = os.pullEvent("monitor_touch")
  print("The monitor on side " .. side .. " was touched at (" .. x .. ", " .. y .. ")")
end
