鼠标拖动

每当按住鼠标按钮并移动鼠标时，都会触发此事件。

返回值

  1. string：事件名称。
  2. number：正在按下的鼠标按钮。
  3. number：鼠标的 X 坐标。
  4. number：鼠标的 Y 坐标。

例子

每当拖动鼠标时都会打印按钮和坐标。

while true do
  local event, button, x, y = os.pullEvent("mouse_drag")
  print(("The mouse button %s was dragged at %d, %d"):format(button, x, y))
end
