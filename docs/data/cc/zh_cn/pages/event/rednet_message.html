红网消息

当通过 Rednet 发送消息时，会触发 rednet_message 事件。

该事件通常由rednet.receive处理，但也可以手动拉取。

rednet_message 事件由顶级协程中的 rednet.run 发送，以响应 modem_message 事件。 rednet_message 事件之前始终有 modem_message 事件。它们是在 CraftOS 内部生成的，而不是由 ComputerCraft 机器发送的。

返回值

  1. string：事件名称。
  2. number：发送计算机的 ID。
  3. any：已发送的消息。
  4. string|nil：消息的协议（如果提供）。

例子

发送消息时打印一条消息：

while true do
  local event, sender, message, protocol = os.pullEvent("rednet_message")
  if protocol ~= nil then
    print("Received message from " .. sender .. " with protocol " .. protocol .. " and message " .. tostring(message))
  else
    print("Received message from " .. sender .. " with message " .. tostring(message))
  end
end

另请参阅

  • modem_message 用于在 Rednet 外部发送的原始调制解调器消息。
  • rednet.receive 等待具有可选超时和协议过滤器的 Rednet 消息。
