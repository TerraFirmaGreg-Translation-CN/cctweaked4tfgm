http_失败

当 HTTP 请求失败时，会触发 http_failure 事件。

该事件通常在 http.get 和 http.post 内部处理，但在使用 http.request 时仍然可以看到。

返回值

  1. string：事件名称。
  2. string：请求的站点的 URL。
  3. string：描述失败的错误。
  4. http.Response|nil：连接成功但服务器响应指示失败时的响应句柄。

例子

打印无法联系网站的错误：

local myURL = "https://does.not.exist.tweaked.cc"
http.request(myURL)
local event, url, err
repeat
    event, url, err = os.pullEvent("http_failure")
until url == myURL
print("The URL " .. url .. " could not be reached: " .. err)

打印不存在的网页内容：

local myURL = "https://tweaked.cc/this/does/not/exist"
http.request(myURL)
local event, url, err, handle
repeat
    event, url, err, handle = os.pullEvent("http_failure")
until url == myURL
print("The URL " .. url .. " could not be reached: " .. err)
print(handle.getResponseCode())
handle.close()
