字符

当在键盘上输入字符时，会触发 char 事件。

char 事件与按键不同。有时，多次按键可能会导致输入一个字符（例如，在某些欧洲键盘上）。同样，有些键（例如Ctrl）没有任何对应的字符。如果您想监听按键本身，则应使用 key。

返回值

  1. string：事件名称。
  2. string：表示按下的字符的字符串。

例子

打印用户按下的每个字符：

while true do
    local event, character = os.pullEvent("char")
    print(character .. " was pressed.")
end
