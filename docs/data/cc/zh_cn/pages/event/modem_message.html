调制解调器消息

modem_message 事件会在任意 modem 的开放频道上收到消息时触发。

返回值

  1. string：事件名称。
  2. string：接收消息的调制解调器一侧。
  3. number：发送消息的通道。
  4. number：发送方设置的回复通道。
  5. any：发送者发送的消息。
  6. number|nil：发送者和接收者之间的距离（以块为单位），如果消息在维度之间发送，则为 nil。

例子

包装 modem 外设，打开通道 0 进行监听，并打印所有收到的消息。

local modem = peripheral.find("modem") or error("No modem attached", 0)
modem.open(0)

while true do
    local event, side, channel, replyChannel, message, distance = os.pullEvent("modem_message")
    print(("Message received on side %s on channel %d (reply to %d) from %f blocks away with message %s"):format(
        side, channel, replyChannel, distance, tostring(message)
    ))
end
