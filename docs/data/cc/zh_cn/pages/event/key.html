钥匙

当终端获得焦点时按下任意键，会触发此事件。

此事件返回一个数字“键代码”（例如，F1 是 290）。该值可能因版本而异，因此建议使用 keys API 中的常量，而不是硬编码数值。

如果按下的按钮代表可打印字符，则 key 事件后将紧接着 char 事件。如果您正在使用文本输入，请改用 char 事件！

返回值

  1. string：事件名称。
  2. number：按下的键的数字键值。
  3. boolean：按键事件是否是在按住按键时（true）生成，而不是第一次按下（false）。

例子

当用户按下每个键以及按住该键时打印每个键。

while true do
  local event, key, is_held = os.pullEvent("key")
  print(("%s held=%s"):format(keys.getName(key), is_held))
end
