警报

alarm 事件会在用 os.setAlarm 启动的闹钟完成时触发。

返回值

  1. string：事件名称。
  2. number：已完成的闹钟 ID。

例子

启动计时器，然后等待其完成。

local alarm_id = os.setAlarm(os.time() + 0.05)
local event, id
repeat
    event, id = os.pullEvent("alarm")
until id == alarm_id
print("Alarm with ID " .. id .. " was fired")
