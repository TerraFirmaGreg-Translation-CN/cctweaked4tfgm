定时器

timer 事件在使用 os.startTimer 启动的计时器完成时触发。

返回值

  1. string：事件名称。
  2. number：完成的定时器的ID。

例子

启动并等待计时器完成。

local timer_id = os.startTimer(2)
local event, id
repeat
    event, id = os.pullEvent("timer")
until id == timer_id
print("Timer with ID " .. id .. " was fired")
