websocket_关闭

websocket_closed 事件在已打开的 WebSocket 连接关闭时触发。

返回值

  1. string：事件名称。
  2. string：已关闭的 WebSocket 的 URL。
  3. string|nil：服务器提供的原因 websocket 被关闭。如果连接异常关闭，这将是 nil。
  4. number|nil：连接关闭代码，指示套接字关闭的原因。如果连接异常关闭，这将是 nil。

例子

当 WebSocket 关闭时打印一条消息（这可能需要一分钟）：

local myURL = "wss://example.tweaked.cc/echo"
local ws = http.websocket(myURL)
local event, url
repeat
    event, url = os.pullEvent("websocket_closed")
until url == myURL
print("The WebSocket at " .. url .. " was closed.")
