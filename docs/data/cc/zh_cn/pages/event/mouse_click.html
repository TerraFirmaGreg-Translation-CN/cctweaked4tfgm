鼠标点击

当用鼠标单击终端时会触发此事件。该事件仅在高级计算机（包括高级海龟和袖珍计算机）上触发。

返回值

  1. string：事件名称。
  2. number：单击的鼠标按钮。
  3. number：单击的 X 坐标。
  4. number：单击的 Y 坐标。

鼠标按钮

多个鼠标事件（mouse_click、mouse_up、mouse_scroll）包含“鼠标按钮”代码。这需要一个数值，具体取决于发生此事件时最后按下鼠标上的哪个按钮。

按钮代码鼠标按钮
1左按钮
2右键
3中键

例子

每次单击鼠标时都会打印按钮和坐标。

while true do
  local event, button, x, y = os.pullEvent("mouse_click")
  print(("The mouse button %s was pressed at %d, %d"):format(button, x, y))
end
