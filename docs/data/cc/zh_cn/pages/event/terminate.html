终止

terminate 事件在按住 Ctrl-T 时触发。

该事件通常由os.pullEvent处理，并且不会返回。但是，os.pullEventRaw 在触发时将返回此事件。

terminate 即使向 os.pullEventRaw 提供了过滤器也会被发送。将 os.pullEventRaw 与过滤器一起使用时，请务必检查事件不是 terminate。

返回值

  1. string：事件名称。

例子

按住 Ctrl-T 时打印一条消息：

while true do
  local event = os.pullEventRaw("terminate")
  if event == "terminate" then print("Terminate requested!") end
end

按住 Ctrl-T 时退出：

while true do
  os.pullEvent()
end
