websocket_消息

websocket_message 事件在已打开的 WebSocket 连接上收到消息时触发。

该事件通常由 http.Websocket.receive 处理，但也可以手动拉取。

返回值

  1. string：事件名称。
  2. string：WebSocket 的 URL。
  3. string：消息的内容。
  4. boolean：这是否是二进制消息。

例子

打印由 WebSocket 发送的消息：

local myURL = "wss://example.tweaked.cc/echo"
local ws = http.websocket(myURL)
ws.send("Hello!")
local event, url, message
repeat
    event, url, message = os.pullEvent("websocket_message")
until url == myURL
print("Received message from " .. url .. " with contents " .. message)
ws.close()
