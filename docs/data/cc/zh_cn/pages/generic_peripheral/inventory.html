size()Source

获取此库存的大小。

返回

  1. number 此库存中的槽数。
list()Source

列出此物品栏中的所有物品。返回一个表，每个槽位对应一个条目。

物品栏中的每个物品由一个包含基本信息的表表示。更多信息可通过 getItemDetail 获取。表中包含物品的 name、count，以及物品 nbt. 的（可能为 nil 的）哈希。这个 NBT 数据本身没有有用内容，但可以用来区分相同物品。

返回的表是稀疏的，因此空槽位为 nil —— 建议使用 pairs 而不是 ipairs 循环。

返回值

  1. { table |无... } 有关此库存中所有商品的基本信息。

用法

  • 找到相邻的箱子并打印其中的所有物品。

    local chest = peripheral.find("minecraft:chest")
for slot, item in pairs(chest.list()) do
 print(("%d x %s in slot %d"):format(item.count, item.name, slot))
end

getItemDetail(slot)Source

获取有关某个项目的 详细信息。

参数

  1. slot number 要获取相关信息的插槽。

返回

  1. table | nil 有关此插槽中项目的信息，如果为空，则为 nil。

抛出

  • 如果槽位超出范围。

用法

  • 打印有关箱子中第一个物品的一些信息。

    local chest = peripheral.find("minecraft:chest")
local item = chest.getItemDetail(1)
if not item then print("No item") return end

print(("%s (%s)"):format(item.displayName, item.name))
print(("Count: %d/%d"):format(item.count, item.maxCount))

if item.damage then
 print(("Damage: %d/%d"):format(item.damage, item.maxDamage))
end

getItemLimit(slot)Source

获取此插槽中可以存储的最大项目数。

通常限制为 64 个项目。然而，某些库存（例如桶或缓存）可以在一个槽中存储数百或数千个物品。

参数

  1. 插槽 number 插槽

返回

  1. number 此插槽中的最大项目数。

抛出

  • 如果槽位超出范围。

用法

  • 计算相邻箱子可以容纳的最大物品数量。

    local chest = peripheral.find("minecraft:chest")
local total = 0
for i = 1, chest.size() do
 total = total + chest.getItemLimit(i)
end
print(total)

pushItems(toName, fromSlot [, limit [, toSlot]])Source

将项目从一个库存推送到另一个连接的库存。

这允许您将一个库存中的项目推送到同一有线网络上的另一个库存。两个清单都必须连接到通过线缆连接的有线调制解调器。

参数

  1. toName string 要推送到的外设/清单的名称。这是赋予 peripheral.wrap 的字符串，并由有线调制解调器显示。
  2. fromSlot number 当前库存中要将物品移动到的位置。
  3. limit? number 要移动的最大项目数。默认为当前堆栈限制。
  4. toSlot? number 目标物品栏中要移动到的位置。如果没有给出，该项目将被插入到任何插槽中。

返回

  1. number 传输的项目数。

抛出

  • 如果要转移到的外设不存在或不是库存。

  • 如果源或目标插槽超出范围。

用法

  • 包裹两个箱子，然后将物品从一个箱子推到另一个箱子。

    local chest_a = peripheral.wrap("minecraft:chest_0")
local chest_b = peripheral.wrap("minecraft:chest_1")

chest_a.pushItems(peripheral.getName(chest_b), 1)

参见还

  • peripheral.getName 允许您获取 包装的 外设的名称。
pullItems(fromName, fromSlot [, limit [, toSlot]])Source

将物品从连接的库存中拉入此库存。

这允许您在同一有线网络上的库存之间传输物品。此清单和源清单都必须连接到通过线缆连接的有线调制解调器。

参数

  1. fromName string 要从中提取的外设/清单的名称。这是赋予 peripheral.wrap 的字符串，并由有线调制解调器显示。
  2. fromSlot number 源库存中要从中移动物品的槽位。
  3. limit? number 要移动的最大项目数。默认为当前堆栈限制。
  4. toSlot? number 当前库存中要移动到的位置。如果没有给出，该项目将被插入到任何插槽中。

返回

  1. number 传输的项目数。

抛出

  • 如果要转移到的外设不存在或不是库存。

  • 如果源或目标插槽超出范围。

用法

  • 包裹两个箱子，然后将物品从一个箱子推到另一个箱子。

    local chest_a = peripheral.wrap("minecraft:chest_0")
local chest_b = peripheral.wrap("minecraft:chest_1")

chest_a.pullItems(peripheral.getName(chest_b), 1)

请参阅还

  • peripheral.getName 允许您获取 包装的 外设的名称。
