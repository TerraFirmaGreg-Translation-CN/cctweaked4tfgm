能量存储

用于与存储能量的方块交互的方法。

这适用于能量存储块以及消耗能量的发电机和机器。

🛈 注意

由于 Forge 能源 API 的限制，无法测量吞吐量（即每个周期使用/生成的 FE）。

更改

  • 新增于版本 1.94.0
getEnergy()获取该块的能量。
getEnergyCapacity()获取该块可以存储的最大能量。
getEnergy()Source

获取该块的能量。

返回

  1. number 该块中存储的能量，以 FE 为单位。
getEnergyCapacity()Source

获取该块可以存储的最大能量。

返回

  1. number 该块的能量容量。
