tanks()Source

获取此液体存储中的所有“罐”。

每个罐要么包含一定量的液体，要么是空的。装有液体的储罐将返回有关液体的一些基本信息，包括其名称和数量。

返回的表很稀疏，因此空储罐将为 nil - 建议使用 pairs 进行循环，而不是 ipairs.

返回

  1. { table | nil... } 有关此流体存储中所有流体的基本信息。
pushFluid(toName [, limit [, fluidName]])Source

将流体从一个流体容器移动到另一个连接的流体容器。

这允许您将当前流体容器中的流体拉到同一有线网络上的另一个容器。两个容器必须连接到通过线缆连接的有线调制解调器。

参数

  1. toName string 要推送到的外设/容器的名称。这是赋予 peripheral.wrap 的字符串，并由有线调制解调器显示。
  2. limit? number 要移动的最大流体量。
  3. fluidName? string 要移动的流体。如果没有给出，将选择任意流体。

返回

  1. number 移动的流体量。

抛出

  • 如果要传输到的外设不存在或者不是流体容器。

另请参阅

  • peripheral.getName 允许您获取 包装的 外设的名称。
pullFluid(fromName [, limit [, fluidName]])Source

将流体从连接的流体容器移至此容器中。

这允许您从同一有线网络上的另一个容器 提取当前流体容器中的流体 。两个容器必须连接到通过线缆连接的有线调制解调器。

参数

  1. fromName string 要推送到的外设/容器的名称。这是赋予 peripheral.wrap 的字符串，并由有线调制解调器显示。
  2. limit? number 要移动的最大流体量。
  3. fluidName? string 要移动的流体。如果没有给出，将选择任意流体。

返回

  1. number 移动的流体量。

抛出

  • 如果要传输到的外设不存在或者不是流体容器。

另请参阅

  • peripheral.getName 允许您获取 包装的 外设的名称。
