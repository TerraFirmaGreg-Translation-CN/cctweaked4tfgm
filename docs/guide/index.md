# Guide

<VersionPill show-core />

TerraFirmaGreg Modern does not fork CC: Tweaked. It takes the upstream JAR as a normal dependency and rewrites everything around it: recipes, progression gates, the creative tab, the quest chapter, and the item-name overrides. This guide separates the two layers so you can tell "this is CC:T" from "this is TFGM".

- [What TFGM changes](/guide/differences) — the full delta, item by item.
- [Recipes](/guide/recipes) — the GregTech rebuild of every CC:T recipe.
- [Turtle upgrades](/guide/turtle-upgrades) — 73 GT tool upgrades.
- [Progression](/guide/progression) — when computers become available, and what they cost.
- [Language & text](/guide/language) — UTF-8 support and the locale overrides.
- [Advanced Peripherals](/guide/advanced-peripherals) — the CC addon TFGM keeps, and the parts it removes.
- [Upstream & versioning](/guide/upstream) — CC:T release cadence and where TFGM sits.
- [Data pipeline](/guide/data-pipeline) — how this site is generated.

::: tip Where to start
If you have never used ComputerCraft, read CC:T's own [getting-started material](https://tweaked.cc/mc-1.20.x/index.html) first. This site documents the *differences*, not the Lua language.
:::
