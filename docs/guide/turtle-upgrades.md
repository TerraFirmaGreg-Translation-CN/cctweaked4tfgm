# Turtle upgrades

<VersionPill show-core />

CC:T ships six vanilla tool upgrades (diamond sword/pickaxe/axe/shovel/hoe + crafting table) plus wireless modems and a speaker. TFGM adds **one upgrade per GregTech material per tool type**, generated by `kubejs/server_scripts/computer_craft/data.js`:

```js
const TURTLE_TOOL_TYPES = [ GTToolType.SWORD, GTToolType.PICKAXE, GTToolType.AXE, GTToolType.SHOVEL, GTToolType.HOE ]
forEachMaterial(material => { /* ... */ event.addJson(
	`computercraft:computercraft/turtle_upgrades/${material.getName()}_${type.name}`, json) })
```

## Generated data file

Each cell writes a JSON file into CC:T's upgrade registry. Click a material row above, or read the shape here:

```json
{
  "type": "computercraft:tool",
  "item": "gtceu:steel_pickaxe",
  "adjective": "upgrade.minecraft.diamond_pickaxe.adjective",
  "allowEnchantments": true,
  "consumeDurability": "always",
  "breakable": "computercraft:turtle_sword_harvestable"
}
```

Points worth knowing:

- **`breakable` is only set for sword, shovel and hoe.** TFGM reuses CC:T's own block tags rather than inventing new ones, and CC:T only defines those three as upgrade-specific harvest tags.
- **The adjective reuses the vanilla keys.** A steel pickaxe turtle is called "Mining Turtle", exactly like a diamond one — TFGM does not add per-material adjectives.
- **`consumeDurability: "always"`** means GT tool durability is really consumed, so turtle mining drains the tool. Combined with `allowEnchantments`, an enchanted GT tool keeps working.

## TFC crop harvesting

`kubejs/server_scripts/computer_craft/tags.js` extends CC:T's hoe tag:

```js
event.add('computercraft:turtle_hoe_harvestable', '#tfc:mineable_with_sharp_tool')
```

TFC models crop harvesting as "sharp tool" rather than "hoe", so this is what makes the GT hoe upgrades actually able to harvest TFC crops.

## What happens on a CC:T upgrade

CC:T 1.121.0 rewrote the upgrade NBT format to keep the equipped item (`RightUpgradeItem` / `UpgradeInfo`). Consequences for a TFGM world:

- Turtles crafted with a GT tool **before** the 1.121.0 bump keep working but lose the stored tool; re-apply the upgrade.
- TFGM's upgrade IDs are `computercraft:<material>_<type>`, unaffected by the format change.
- The recipe that applies an upgrade (`computercraft:impostor_shaped`, pattern `#T`) writes the item into the upgrade data automatically.

::: warning Not in the creative tab
Turtles — upgraded or not — do not appear in the CC creative tab (see [what TFGM changes](/guide/differences#creative-tab)). Crafting still works.
:::
